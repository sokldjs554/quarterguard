# LLM 설명·인용의 제한적 자동 검사

새 유료 LLM 호출 없이 기존 GPT 응답 4개를 재검사하고 AI가 만든 합성 개발 반례 21개를 별도로 검사했다. [현재 결과](../artifacts/explanation-v2-final.json), [최초 결과](../artifacts/explanation-v2.json), [기존 실제 응답](../artifacts/live-openai.json)을 모두 보존한다. 합성 텍스트는 새 모델 출력이나 사람 평가가 아니다. LLM-as-judge는 사용하지 않았다.

## 검사한 범위

`quarterguard/explanation_audit.py:audit_explanation`은 기존 구조 필드 exact match와 함께 다음을 확인한다.

- 인용 ID 순서, 정본 Fact의 값/기업/문서 해시/URL/페이지/행/열 일치.
- 명시적 성장률의 Decimal 비교와 표시 자릿수 반올림.
- 단순 금액을 원 단위로 정규화하고, 같은 문장에 명시된 연도·분기·연결 범위·개월 수의 근거와 연결.
- 연도/분기/개월·연결/별도·통화·단위의 명시적 충돌, 근거 없는 수치, 거부 판정을 뒤집는 표현.
- 임의 URL 인용, 출처 없는 숫자, “개별”처럼 범위가 모호한 표현, 부정문 해석 필요 표시.

새 규칙의 독립 AI 리뷰에서 `3분기`와 `3 분기`/`Q3` 사이의 금액 연결 누락이 발견됐다. 재현 테스트를 먼저 추가하고 수정했다. 최초 17개 합성 결과는 덮어쓰지 않았고, 두 표기 변형을 추가한 현재 21개 개발 반례의 기대 판정은 21/21 일치한다. 이는 합성 회귀 기준을 충족했다는 뜻이며 일반적인 환각 탐지 정확도 100%가 아니다.

## 기존 실제 GPT 4개 재평가

구조 필드와 정본 인용 대조는 4개 모두 통과했다. 자유 문장 규칙은 2개를 사람 검토 대상으로 표시했다.

|기존 사례|새 표시|의미|
|---|---|---|
|분기 매출 증감|발견한 규칙 위반 없음|6.7916%와 명시된 2024년/3분기/연결이 근거와 맞음. 전체 의미 정확도 인증은 아님|
|분기·누적 혼동|부정문 검토 필요|“동일하지 않아”의 의미를 단순 키워드 규칙만으로 확정하지 않음. 이것을 실제 문장 오류로 단정하지 않음|
|근거 없음|발견한 규칙 위반 없음|요청 연도 2025와 근거 부재 설명. 공개 작업지는 여전히 2024 정본이므로 문맥을 구분|
|누적 차감|범위 표현 검토 필요|“3분기 개별 매출”의 개별이 연결/별도 또는 단독 기간을 뜻하는지 모호함|

**2개 표시 = 2개 오류 확정이 아니다.** 네 응답 모두 `semantic_verified:false`, `human_review_required:true`다. 아직 전문가나 사용자가 의미를 검수하지 않았다. 규칙에서 발견하지 못한 숫자-항목 연결, 복합 금액, 부정·추정·조건문, 생략된 주어/범위도 남을 수 있다. `no_detected_rule_violation`을 답변 전체 정확도나 금융 감사 의견으로 바꾸어 표현하지 않는다.

## 재현과 사람 검토

```sh
python -m unittest tests.test_explanation_v2 -v
python -m quarterguard.evaluate_explanations_v2 --output artifacts/explanation-v2-replay.json
```

출력 파일은 신규 이름이어야 하며 기존 결과를 덮어쓰지 않는다. 사람은 원문 위치와 도구 결과를 나란히 보고 문장별로 수치·항목·기간·범위·단위를 표시한 뒤, 참/거짓/모호/판단 불가와 이유를 기록해야 한다. [사용자 검증 양식](validation-kit/session-template.md)의 관찰/의견과 분리해 기록한다. 아직 수행 기록은 없다.

새 모델 API 호출과 추가 API 비용은 0회/$0이다. 과거 4회 청구액은 조회하지 않았으며, CPU·저장·다운로드 비용을 포함한 총비용을 주장하지 않는다. 새로운 생성 모델 평가를 실행하려면 대상/모델/호출 수/토큰 상한/예상 비용을 구체화해 별도 승인을 받아야 한다.

후속 리뷰에서 `3 개월`과 영어 연결 범위의 금액 연결도 보강했다. 첫 17개와 중간 19개 결과를 모두 보존하고, 월 표기·혼합 범위 반례 두 개를 추가한 21개 결과를 별도 파일에 기록했다. 추가 모델 호출은 없다.
