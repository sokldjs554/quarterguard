# 데이터와 재현 범위

- 기업: 삼성전자 1개. 문서: 발행사 공식 영문 IR 보고서 2건.
- 2024 반기 보고서 287페이지, 2024 3분기 보고서 179페이지. 합계 466페이지 중 손익 표 4페이지를 구조화하고 나머지 462페이지는 로컬 본문으로 분리한다.
- 표 위치: 반기 연결 p48·별도 p104; 3분기 연결 p34·별도 p89.
- 6개 항목: 매출, 매출원가, 매출총이익, 판매관리비, 영업이익, 당기순이익.
- 표마다 8개 열: 2024/2023 × 단독분기/누적 × KRW 백만/USD 천. 2문서 × 2범위 × 6항목 × 8열 = **192개 수치 사실**.
- 데이터 기준은 2024-09-30까지다. 조사·다운로드일은 2026-10-29이며 최신 투자 데이터를 제공하지 않는다.
- [원문 manifest](../data/sources.json): URL, SHA-256, 페이지 수와 기준일. [사실](../data/facts.json): 출처 위치를 가진 개별 수치.

## 파싱

`pypdf`로 페이지별 텍스트를 읽는다. 손익 표의 범위·단위·기간·열 헤더를 검증하고 8개 열을 하나씩 문맥 레코드로 만든다. 허용한 레이아웃만 지원한다. 단위/열 헤더/숫자 개수 불일치 시 예외를 발생시킨다. PDF 좌표 기반 범용 표 탐지·OCR·다른 기업 대응·한글 DART PDF 파서는 구현하지 않았다. 본문은 로컬에서 표와 분리되지만 현재 검색 평가는 수치 셀에 한정한다.

`fixed_word`는 공통 헤더 아래 재구성한 숫자 표를 180자씩 잘라 검색한다. 나머지는 각 셀에 항목·연결 범위·기간·단위를 붙인다. 본문 전체 검색과 표 검색을 비교한 실험은 아니다.

## 수집

```bash
python -m quarterguard.ingest --download
```

원본은 gitignore의 `work/raw/`에 저장된다. 추출된 facts와 sources를 갱신한다. 원문 변경으로 해시가 바뀌면 평가도 새로 실행해야 한다. 동일 파일에서는 수치·해시가 재현되는지 `scripts/check_artifacts.py`로 검사한다.

## DART

```bash
# 본인 환경에 DART_API_KEY를 안전하게 설정한 후
python -m quarterguard.dart --corp 00126380 --year 2024 --report 11014
```

공식 API 수집기는 코드로 제공한다. API 키가 없어 실제 DART 호출은 실행하지 않았다. 이 수집기의 출력은 기본 IR 코퍼스에 자동 병합되지 않는다. DART의 계정 ID, 보고서·수치 필드, 공시 링크를 보존하되 본 데모의 PDF 페이지로 위장하지 않는다. 추가 문서의 레이아웃 검증·독립 정답 검토 후 통합해야 한다.
