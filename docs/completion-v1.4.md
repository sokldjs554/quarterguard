## 1–2. 원문과 질의의 수정 전후

고정된 2024/2023 헤더를 명시적 보고 기간에 맞추는 검사로 바꾸고, 금액의 제한된 줄바꿈·헤더 쉼표를 처리했다. 단위/통화 순서, 반복된 연도, 표 범위, 8개 값의 행 경계가 모호하면 거부한다. `Adjusted Gross profit`을 정식 항목으로 잘못 읽는 문제도 회귀 테스트 후 수정했다. [파서 코드와 제한](parser-v2.md).

|자료 / 용도|원문 PDF 단계|fixture 단계 및 해석|
|---|---|---|
|2024 삼성 반기·Q3, 개발 회귀|4개 표 192개 정본의 전체 공개 필드 동일|기존 정본 재생과 구분|
|2025 삼성 반기·Q3, 알려진 실패 수정|0/4 → 4/4 표, 192개 추출 중 기존 KRW 정답 64/64 일치|나머지 128개까지 독립 정답 검수했다는 뜻 아님|
|2023 삼성·현대, 첫 별도 동결 평가|최초 수정본도 0/5 표, 0/80 정답|질의 20/24. 첫 실패 보존|
|같은 2023 자료, 결과 공개 후 회귀|4/5 표, 64/80 수치·인용, 질의 20/24, 계산 5/6|질의 24/24, 계산 6/6. 원문 현대 표는 여전히 실패|
|2022 삼성 Q3, 다음 별도 동결 평가|1/1 표, 16/16 수치·인용, 질의 8/8, 계산 2/2|fixture도 8/8·2/2. 작은 표본|

원문 단계는 공식 PDF를 실제 다운로드·해시 확인·텍스트 추출·파싱한다. 파싱된 값 중 고정 정답과 맞는 항목을 **평가용 격리 정본 등록**에 넣고 검색·계산한다. fixture 단계는 준비한 정답 수치를 직접 넣는다. 제품의 정본 192개를 늘리거나 새 기업을 공개 작업지에 등록하지 않았다.

2023 첫 결과는 후속 수정에 사용했으므로 최종 보류셋 성능이라고 쓰지 않는다. 2022 자료·질의는 다음 평가 전에 따로 동결했고, 첫 실행 및 행 경계 보강 후 재검증을 모두 보존했다. 비교 연도 금액 일부는 다른 자료와 겹친다. 새 정답은 같은 작업의 별도 AI가 공식 표에서 작성했으며 **사람·전문가 검수는 없다**. [공식 출처, 동결 해시, 정답 작성, 모든 실패](evaluation-v2.md).

기존 자연어 5개는 후보 Recall@5 5/5·top1 3/5이나 모두 조건이 빠져 확인 필요이며 검증된 답변은 0개다. 한국어/영어의 기업·항목·기간·범위·통화·단위를 보존하고 알 수 없는 조건/부정/충돌은 막는다. 원문이 맞아도 제품 정본 등록은 별도이며, 검색 후보는 답변 인증이 아니다. [검색 결과](search-v2.md).

## 3. 실제 리랭킹의 득실

동일 top20 후보·질의·정답에서 CPU ONNX cross encoder를 실행했다. 개발 36개 Recall@1은 혼합 검색 1.000 → 리랭커 0.806, MRR@5 1.000 → 0.903, p50 1.52 → 149.47ms다. 첫 2023 정답 질의 14개는 Recall@1 둘 다 0.500, MRR 0.714 → 0.696이다. 마지막 2022 정답 질의 6개는 Recall@1 0.667 → 0.833, MRR 0.833 → 0.917이지만 단어 TF-IDF는 1.000이며 리랭커 p50은 104.66ms다.

기본 검색에는 넣지 않았다. 문맥 필터는 신경망 리랭킹이 아니고, 필터 후 후보 하나인 결과는 개선 증거가 아니다. 기존 고정180자/셀 단위 청킹과 두 실제 임베딩 모델 결과, 정보량 차이·CPU/캐시·모델 해시는 [실험 보고](ranking-v2.md)에 기록했다. 이 실험은 fixture 후보 검색이며 PDF 전체 처리 성능이 아니다.

## 4–5. 설명과 MCP

기존 실제 GPT 4개는 구조 필드·정본 인용이 맞았지만, 문장 규칙상 2개에 부정문/모호한 범위의 사람 검토 표시가 생겼다. 오류 2개가 확정된 것은 아니다. 합성 반례 21/21 기대 판정은 규칙 회귀이며 일반 환각 탐지 성능이 아니다. 새 생성형 호출·LLM-as-judge·사람 의미 검수는 없다. 모든 응답의 의미 인증은 false다. [규칙과 남은 한계](explanations-v2.md).

MCP 실제 stdio 8개 흐름과 직접 잘못된 입력 5개를 확인했다. 실패 주입 4개와 스키마 변형 10개는 모의 검사로 분리했다. 실패 시 새 보류 결과·빈 근거를 반환하고, 실패한 도구 이름/입력/지연도 기록한다. 이전 성공을 새 결과처럼 돌려주지 않는다. 검색→근거→대조→계산/보류는 규칙 기반이며 LLM이 도구를 계획하거나 선택하지 않는다. [실제 trace 및 모의 실패](mcp-v2.md).

## 6–7. 사람이 이어서 수행할 일

사용자는 지인 일반 사용자와 회계 관련 참여 가능자가 있다고 답했다. 역할·경력·동의·세션은 아직 확인되지 않았다. 일반 사용자에게는 원문 찾기·조건 변경·보류 이유 이해를, 회계 관련 참여자에게는 추가로 기간/범위/단위 해석을 요청하도록 준비했다. 20–30분 공개 자료 과제이며 비공개 금융 자료는 필요 없다.

- [참여자 안내와 두 경로](validation-kit/recruitment-status.md), [동의](validation-kit/consent.md), [과제](validation-kit/tasks.md), [빈 세션 기록](validation-kit/session-template.md).
- 고객 환경이 생기면 [권한·자료·배포 방식·범위 확인표](validation-kit/customer-access-checklist.md)를 먼저 작성한다. 실제 금융기관 고객 배포·사용은 0건이다.
- [2025 파서 코드](code-review-kit/01-parser-2025.md): 헤더의 어떤 불일치에서 거부해야 하며, 192개 추출과 64개 정답 대조는 왜 다른가?
- [기간·범위 차단](code-review-kit/02-comparison-guards.md): 같은 금액이라도 분기/누적·연결/별도가 다르면 왜 비교를 멈추는가?
- [DART/IR 단위](code-review-kit/03-dart-ir.md): 원과 백만원을 어디서 정규화하며, 단독/누적 필드와 중복 후보는 어떻게 구분하는가?

각 코드 안내에 함수·테스트·입력·출력과 거부 예제가 있다. [본인 빈 기록지](code-review-kit/review-template.md)에 직접 확인한 설명과 출력만 남기면 된다. AI가 시연한 결과를 지원자의 오류 발견·수정·검토 완료로 기록하지 않았다.

로컬 Python 141개 통과, Node 메모/CSV 테스트 통과, 이전 정본·평가 artifact 일관성 통과. Chromium PC1440×1000/모바일 크기390×844에서 기존 흐름37, provider 모의7, 검색 UI 모의10, 실제 백엔드 검색·새 집계10개를 통과했다. 캡처의 `d4ba1e3`는 코드 구현 커밋이며, 이후 문서·증거 추가 커밋과 구분한다. `*-v1.4-verified.png`가 표시 오류 수정 후 캡처다. 최초 캡처도 보존했으며 `evaluation-v1.4.png`의 `undefined/8`은 당시 집계 필드 연결 오류로, 현재 코드와 검사는 8/8을 확인한다. 물리 휴대폰 검사나 발행사 PDF 브라우저 렌더링 성공을 주장하지 않는다. [로컬 증거](../artifacts/validation-v1.4-local.json), [화면](images/desktop-v1.4-verified.png).

최종 커밋은 파일 자체에 자기 SHA를 기록하는 순환을 피하기 위해 [v1.4.0 릴리스](https://github.com/sokldjs554/quarterguard/releases/tag/v1.4.0)에 GitHub main·Render 배포 ID/커밋·공개 `/health`를 함께 기록한다. 배포 뒤 직접 HTTPS 시도와 TLS 검증 중계의 PC/모바일 검사, 실제 DART 요청/캐시, 정적 파일 해시도 그 릴리스의 JSON 근거로 제공한다. 직접 HTTPS가 인증서 신뢰 문제로 실패하면 성공으로 바꾸어 표현하지 않는다.

이 문서 작성 시 새 유료 API 호출은 0회/$0, 새 DART 호출은 아직 0회다. 배포 후 무료 DART 검사 횟수는 릴리스의 별도 원장으로 확정한다. 기존 Actions GPT4/DART4·공개 DART4 기록은 보존했다. 실제 청구액은 조회하지 않았다. 유료 플랜 전환·추가 서비스·LLM 호출은 실행하지 않는다. 공개 LLM은 비용 승인과 지속 원장 등 요건이 충족되지 않아 차단한다. DART는 고정4대상·캐시·간격·횟수 제한을 유지하나 무료 서버 재시작 시 원장이 초기화될 수 있다.

## 9. 지원서에 사용할 수 있는 표현

> 공식 금융 PDF의 연도 헤더·수치 줄바꿈·행 경계 오류를 분석해 파서를 보완하고, 2024 정본 192개 회귀와 2025의 알려진 실패 4개 표를 검증했습니다. 별도 기간·기업 자료를 고정해 원문 파싱과 fixture 진단을 나눴으며, 현대자동차 표의 미지원과 첫 평가 실패도 공개했습니다. 한국어·영어 검색 조건을 보존하고 비교 조건 불일치 시 보류하는 규칙 기반 MCP 흐름을 구현했습니다. 실제 cross encoder를 동일 후보에서 비교했으나 일관된 개선이 없어 기본 검색에 적용하지 않았습니다.

AI 도구로 구현했다는 사실과 본인이 실제 읽고 설명·실행한 범위를 함께 밝혀야 한다. 아직 “전문가 검수 완료”, “금융기관 고객 배포”, “현업 협업 성과”, “LLM 자율 에이전트”, “금융 답변 정확도100%”, “리랭킹 전반적 향상”, “본인이 버그를 발견·수정했다”는 주장은 근거가 없다. 참여 세션과 본인 검토를 마치면 실제 기록을 바탕으로 지원 문장을 갱신할 수 있다.
