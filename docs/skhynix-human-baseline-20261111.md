# 본인 작성 SK하이닉스 5문항 — 원본 고정·원문 대조·첫 제품 평가

## 작성 출처와 보존

프로젝트 작성자 윤기혁은 질문·답안5건을 직접 작성했고 AI를 사용하지 않았다고 명시했다. [수신 원본](../data/skhynix-human-20261111/submitted.md), [구조화 사본](../data/skhynix-human-20261111/cases.json), [실행 전 고정 해시](../data/skhynix-human-20261111/freeze.json), [작성자 확인](../data/skhynix-human-20261111/authorship-confirmation.json)을 분리했다. 최초 고정 시점의 작성자 확인 대기 상태도 덮어쓰지 않았다.

작성자 진술에 근거한 사람 작성 사례이며, 작성 과정을 AI가 직접 관찰했다는 뜻은 아니다. 작성 날짜·환경은 미제공이다. AI는 수신 후 기록 형식 정리·원문 다운로드/텍스트/이미지 대조·검산·제품 실행을 수행했다. 원래 질문·답안 내용은 수정하지 않았다. 본인 작성 사례5건이며 새 외부 참여자나 b의 신규 검수로 세지 않는다.

## 원문 확인

공식 배포처 SGX의 [SK hynix Inc. 2025 Offering Circular](https://links.sgx.com/FileOpen/SK%20hynix%20Inc._2025%20-%20Final%20Offering%20Circular%20%289.4.25%29.ashx?App=Prospectus&FileID=67332)를 HTTPS로 내려받았다. PDF291쪽,2,621,486바이트, SHA256 `3b06e43298560053e2b6d9a79861c1ef505880879142242200e2d2ce06421f7c`.

자료명은2025 Offering Circular지만 이 문항이 참조하는 재무제표는 **2024·2023 연결 연간 자료**다. 같은 PDF 앞부분의2025 중간재무제표와 혼합하지 않았다.

|---|---:|---|
|F-73|191|Consolidated Statements of Financial Position, December31,2024 and2023 — 시점 잔액|
|F-75|193|Consolidated Statements of Comprehensive Income (Loss), Years ended December31,2024 and2023 — 연간 흐름|
|F-146|264|Notes24.Revenue, (2) 제품·서비스 유형별2024·2023 연간 매출|

통화KRW·표시 단위백만 원·환산 배율1,000,000·연결범위CFS를 확인했다. AI가 원문 텍스트와 렌더링 이미지3쪽을 읽어 [지정 셀10개](../artifacts/skhynix-human-20261111/source-review-ai.json)를 대조했다. 이는 사람이 추가 검수한 결과나 제품 파서가 추출한 정본이 아니다. F-146의 합계는 (2)표에서 Others 다음의 **행명이 비어 있는 합계 행**으로 기록해 다른 동일 금액의 합계와 구분했다.

검산은 입력한 수치를 Decimal로 다시 계산한 것이다. 원문 표를 제품이 자동 파싱하고 이 답안을 생성했다는 뜻이 아니다. 현금·재고를 연간 손익으로 간주하거나 시점 잔액에 임의의12개월 기간을 부여하지 않았다.

## 수정하지 않은 제품의 첫 실행

기준 커밋`4024c4e0d74d894bf912ad2d1ca45ad8f435e6b3`. 제품 코드·등록 정본은 변경하지 않았다. [첫 결과](../artifacts/skhynix-human-20261111/first-baseline/report.json)를 보존했다.

|실행 범위|결과|의미|
|---|---|---|
|원문 PDF→pypdf 추출→기존 parse_statement()|3쪽 모두`UNSUPPORTED_LAYOUT: scope`,정본0개|선정된3쪽0/3지원. PDF를 실제 읽었으나 파싱에 실패한 결과|

|제출한 전체 머리말+원문 질문|5건 모두근거0건|머리말의여러 연도·쪽수 설명/부정 표현도 단일 수치 검색기에서 미지원. 질문 자체가 틀렸다는 판정은 아님|

|원문2셀을 수동 정본으로 준비한 격리 compare() 검사|`issues=['NEGATIVE_BASE']`, `status='needs_review'`, `growth_pct=null`|음수 기준값 방어만 확인. 파서 성공이나 전체 질문4번 자동 해결이 아님|

질문4·5에서 보류됐다는 사실만으로 정답 처리하지 않는다. 실제 검색은 관련 재무 사유를 이해해 판단한 것이 아니라 미지원 조건으로 막혔다. **제품이 원문부터 위5개 답안을 자동 생성한 결과는 없다.** 모든 검색 실행은 같은5개 원문 질문의 변형이며15개 독립 문항으로 세지 않는다.

수동 정본 검사는`Operating profit (loss)`를 기존 표준항목`Operating profit`으로, 연간 기간을12개월YTD로 표시했다. 이 변환과2개 금액은 AI가 준비했고 기존 등록 소스를 일시적으로 대체하는 메모리 패치에서만 실행했다. 공개 정본은 그대로다. [추가 문맥 검색](../artifacts/skhynix-human-20261111/explicit-context-supplement.json)도 첫 실패와 분리했다.

## 남은 범위

- SK하이닉스 연간 재무제표의 회사·연도·연결범위·단위·주석 열을 검증하는 파서 및 출처 등록은 미구현.
- 시점 잔액과 기간 실적을 구분하는 자료형/계산 조건, 제품 매출 비중·복수 항목 추세·재고 개월수의 질문 해석은 미구현.
- 현재 음수 기준값 차단은 확인했으나 흑자 전환과 차액을 자동 설명하는 전체 흐름은 미검증.
- 이번 입력은 최초 제품 실행 전 고정한 새 회사·문서·사람 작성 질문이었다. 이미 원문·정답·실패를 공개했으므로 이후 수정에 사용하면 개발/회귀용으로 표시한다. 수정 후 다시 실행한 결과를 새로운 맹검 평가라고 부르지 않는다.
- 새 유료 API호출0회, 새 LLM응답0건. 이5건을 대상으로 한 유료 생성은 이전16회 승인에 포함되지 않는다.
- b의 v9 실제 응답 재검수는 이번 본인 작성 질문 수신과 별개이며 여전히 대기다.

## 재현

공식 PDF를 내려받아 SHA256을 확인한 뒤 실행한다. 출력 경로는 새 경로만 허용한다.

```bash
PYTHONPATH=. python scripts/evaluate_skhynix_submission.py \
  --pdf /path/to/offering-circular.pdf \
  --output work/skhynix-my-baseline
```

스크립트는 유료 API를 사용하지 않는다. 공식 PDF 전체를 저장소에 복제하지 않고 URL·해시·선정3쪽의추출 텍스트·실제 실행 결과를 남겼다. 기존 실패 결과·v9원응답·사람 검수 기록은 보존한다.
