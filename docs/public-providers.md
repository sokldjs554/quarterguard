# 공개 API의 실행 범위와 비용 통제

2026-10-29 구현. 실제 공개 배포 검증 기록은 [최종 보고](completion-report.md)에 별도로 남긴다. 기능을 구현했다는 사실과 실제 외부 호출을 구분한다.

## DART

서버 `DART_API_KEY`가 있으면 삼성전자 2024 반기/3분기 × 연결/별도 **4개 고정 조회**만 허용한다. 각 응답에서 매출/영업이익의 분기/누적 금액 4개를 IR 정본과 대조한다. 임의 기업·연도·URL을 입력받지 않으며 코퍼스를 덮어쓰지 않는다. CFS/OFS는 DART 응답 자체의 독립 필드가 아니라 요청 `fs_div`에 근거한다.

사용자가 버튼을 누를 때만 조회한다. 성공 응답 24시간 캐시, 전역 60초 호출 간격, UTC 일 8회/누적 200회 시도 제한, 동시 외부 실행 1개를 적용한다. HTTP 오류·타임아웃도 제한을 소비하며 자동 재시도하지 않는다. **무료 Render의 SQLite 기록은 인스턴스 재시작/배포 시 사라질 수 있다. DART의 일/누적 제한은 해당 기록 수명 기준이며 계정 전체의 영구 한도가 아니다.** DART는 무료 API이며 키 소유자의 다른 서비스 호출은 통제하지 않는다.

## LLM: 구현됨, 기본 차단

규칙 기반 MCP가 먼저 고정 사례를 실행하고 기존 gold의 상태·값·인용·거부 이유와 일치해야 설명을 요청한다. 사례는 `qoq-revenue`, `ytd-trap`, `no-evidence`, `reconcile-revenue` 네 개다. 사용자가 임의 프롬프트/모델/출력 길이를 지정할 수 없다. 기존 작업지·저장 결과·MCP 실행은 그대로 사용할 수 있다.

유료 호출을 켜려면 **모든 조건**이 필요하다.

- 서버 측 `OPENAI_API_KEY` (GitHub Secret은 Render에 자동 전달되지 않음)
- 사용자 비용 승인 후 운영자가 `QG_PAID_APPROVAL=gpt41mini-20-attempts-usd020-v1` 설정
- 실제 별도 마운트 경로의 SQLite 기록 `QG_LEDGER_PATH`와 `QG_LEDGER_DURABLE=true`
- 전역 중단 변수 `QG_PROVIDERS_DISABLED`가 `true`가 아닐 것

기본 무료 Render 파일시스템은 재시작 시 기록을 보장하지 않아 유료 호출을 켤 수 없다. 단순 boolean 설정으로 이 조건을 우회할 수 없다. 마운트 검사는 운영자의 지속성 확인을 보완할 뿐, 임의 다른 마운트의 영구성을 증명하지 않는다. 기록 볼륨 삭제/교체, 다중 서비스 복제, 계정의 다른 키 사용은 이 앱의 예산 범위 밖이다. 현재 유료 디스크·유료 서비스 전환은 하지 않았다.

승인을 요청할 수 있는 구체 범위는 **모델 `gpt-4.1-mini-2025-04-14`, 총 최대 20회 시도, UTC 일 최대 5회, 60초 간격, 성공 응답 24시간 캐시**다. 전체 요청 JSON UTF-8 12,000 bytes 이하, 출력 최대 700 tokens, 자동 재시도 없음, `store:false`. [모델 가격 문서](https://developers.openai.com/api/docs/models/gpt-4.1-mini)의 입력 $0.40/백만·출력 $1.60/백만 tokens 기준, 입력/프로토콜 여유를 포함해 시도당 $0.01·총 **$0.20 이내로 잡은 보수적 예상 예산**이다. 이는 청구 계정의 강제 달러 한도나 향후 가격 보장이 아니다. 호스팅/지속 저장 비용은 제외하며 별도 승인 없이는 추가하지 않는다. 가격·모델·요청 크기 변경 시 재산정과 승인 갱신이 필요하다.

SQLite `BEGIN IMMEDIATE`로 요청 전에 시도를 원자적으로 예약한다. 실패·타임아웃·응답 후 서버 중단도 예약을 소비한다. 따라서 청구액을 받지 못해도 반복 호출로 시도 한도를 넘지 않는다. 사용량 token과 공개 단가의 예상 비용을 표시하며 **실제 청구 비용은 조회하지 않아 `null`**로 둔다. 구조화 상태·수치·인용·원인 불일치는 실패로 처리하고 성공 캐시로 저장하지 않는다. 한국어 설명 문장 전체의 정확도는 자동 검증/사람 검수를 거쳤다고 주장하지 않는다.

## 표시·보안·기록

`GET /api/providers`는 키 값 없이 사용 가능 여부/차단 이유/시도 수/한도를 반환한다. `POST /api/providers/{provider}/{target}`만 외부 호출을 일으킨다. 브라우저 초기 로딩이나 저장 결과 재생은 유료 API를 호출하지 않는다.

- `live_provider_request`: 외부 요청 시도 1회. 실패/타임아웃도 포함하며 성공 여부는 `status`로 구분.
- `cached_provider_response`: 과거 성공 응답 재사용, 이번 외부 호출 0회. 원래 생성 시각과 현재 제공 시각을 함께 표시.
- `blocked`: 외부 호출 0회. 키/승인/지속 기록 등의 이유 표시.

키는 환경 변수에서 서버 HTTP 헤더/쿼리로만 읽으며 API 응답·오류·저장소에 넣지 않는다. 원격 예외 본문은 브라우저에 전달하지 않는다. 공개 원장에는 요청 ID·고정 대상·시각·허용 필드 결과만 저장한다. 임의 사용자 입력, 브라우저 개인 메모는 공급자에게 보내지 않는다. 공개 인증 없는 데모이므로 타인이 허용 시도를 소진할 수 있다. CAPTCHA나 사용자별 인증 할당량은 구현하지 않았으며, 이를 실제 다중 사용자 운영 준비 완료로 표현하지 않는다.
