## 지원서 본문 초안

금융 공시의 숫자는 값뿐 아니라 기간·연결 범위·통화·단위가 같아야 비교할 수 있다는 문제에서 QuarterGuard를 개발했습니다. AI 코딩 도구를 활용해 공식 문서의 표·행·열과 계산 결과를 연결하고, 조건이 맞지 않으면 계산을 보류하도록 구성했습니다. 삼성전자 분기 비교에 더해 SK하이닉스의 연간 실적·연말 잔액·제품 매출 비중과 Apple SEC HTML의 선택 표를 지원합니다.

저는 기간 비교와 DART 단위 환산·중복 후보 거부 코드를 직접 검토하고 관련 테스트를 보강·실행했습니다. 도구의 실제 조건 실행 이력과 입력을 별도로 재계산한 진단을 구분하는 코드·테스트도 제출했습니다. 또한 AI 없이 직접 작성한 Apple 질문7개를 수정 전 평가에 사용했습니다. 최초 근거 검색0/7을 보존하고 원문 지원을 추가한 뒤, 같은 개발 사례7/7과 합성 변형19/19를 확인했습니다. 이 수치를 새 문서 전반의 정확도로 확대하지 않았습니다.

LLM 설명은 구조 필드와 문장 의미를 나누어 평가했습니다. 실제 호출에서 구조 필드가 맞아도 금액 단위를 잘못 표현한 사례를 보존하고 후속 검사로 차단했습니다. 실제 cross-encoder 리랭킹도 동일 후보군에서 비교했으며, 정확도와 지연시간의 절충 때문에 일관된 이득이 없는 방법을 기본 검색에 적용하지 않았습니다. 학생 참여자와 금융 업무 경험이 있는 지인의 사용 의견을 받아 원문 근거·비교 조건·보류 후 복구 동선을 개선했습니다. 공개 데모 배포와 CI·회귀 검증까지 연결했으며, 실제 금융기관 고객 환경 배포와 구분해 기록하고 있습니다.

## 이력서 프로젝트 항목

**QuarterGuard — 금융 공시 근거·비교 조건 검토 도구**

- AI 코딩 도구를 활용해 Python/FastAPI·MCP 기반 금융 문서 검토 흐름 구축. 기간·연결 범위·통화·단위·음수 기준값을 검사하고 계산 또는 판단 보류.
- 공식 PDF와 SEC HTML의 지원 표를 파싱하고 문서·쪽·행·열을 수치와 연결. 본인 작성 Apple7질문의 최초0/7과 수정 후 개발7/7을 분리 보존.
- 기간2개·DART3개·기간 진단1개 테스트를 직접 보강·실행한 기록 확보. 이번 전체 자동 회귀339개 실행(1skip)과 본인의 과거 로컬143개 실행을 구분.
- 실제 임베딩·cross-encoder 비교 및 LLM 구조/문장 평가. 실제 모델 도구 선택4과제 중3개 기준 일치,1개는 미조회 근거 계산 시도로 차단된 결과 공개.

## 트레져러 공고와 연결할 설명

- **태스크 프롬프트·평가셋:** 실제 생성 응답과 저장 도구 결과 재생, 구조 검사와 사람 의미 판정을 구분했다. 실패와 미확인을 공개했다.
- **파서·청킹·임베딩·리랭킹:** 동일 후보/정답 기준의 검색 실험과 정보량 차이·fixture 조건·지연시간을 함께 기록했다.
- **MCP 도구·가드레일:** 실제 MCP 입출력과 제한형 모델 선택을 실행하고, 미조회 근거·문맥 불일치·오류 후 이전 성공 노출을 차단했다.
- **고객 환경에 빠르게 배포하는 목표:** 공개 데모를 사용자가 검토할 수 있게 운영하고 사용 의견을 반영한 경험으로 설명한다. 금융기관 내부망·비공개 데이터·조직 승인을 받아 배포한 사실은 없다.

입사 후 접근 방식을 묻는다면 다음은 **향후 제안**으로만 말할 수 있다: 첫 주에 사용자 업무·자료 사용 권한·성공/보류 기준을 정하고, 둘째 주에 좁은 범위의 근거 검증 기능을 구현·평가하며, 셋째 주에 허가된 환경에서 실제 사용 관찰, 넷째 주에 오류 복구·로그·비용을 점검한 기능을 배포하겠다. 실제 회사의 일정·절차에 맞추겠다는 전제를 둔다.

## 최신 제출 기록과 남은 확인

- Apple/SK 11과제의 주요 화면 결과 수신: 9개는 명시된 후속 미확인 없음, A7·S4는 파일 저장·내용 또는 질문 변경 후 상태가 미확인이다. 수행자는 기존 참여자 b로 확인됐고 일시·환경·도움은 미제공. SK 위치·값은 데모 화면 확인이며 직접 원문 PDF 검수로 바꾸지 않는다.
- 제품 동일 모델4건: 제출 설명 참2 / 거짓2; 구조 일치3 / 불일치1; 근거 ID 일치4(빈 목록1 포함). 기존 참여자 b의 직접 판정으로 후속 확인됐다.
- v9 16건: b가 원응답과 근거를 직접 대조한 사람 판정 참13 / 모호3. 구조·근거 ID는 16건 일치(빈 목록1 포함). [출처 표기 오류 정정](validation-kit/final-followup-20261112/v9-human-review-correction.json)에 사용자 확인을 보존했다. 판정 내용은 변경하지 않았다.
- A7·S4의 다운로드 파일과 실제 서버 응답 대조, 질문 변경 후 이전 결과 제거를 [자동 브라우저 검사](final-export-verification-20261112.md)로 확인했다. AI 점검에서 발견한 S4 제목 오류를 수정했다. 사람 검수 또는 사용 시간 개선 수치로 세지 않는다.
- [남은 두 저장 과제](validation-kit/final-followup-20261112/remaining-checks.md)는 아직 필요하다. 응답20건의 b 직접 검수는 확인됐지만, 새 생성 실험이나 생성 품질 향상으로 해석하지 않는다.

두 모델·배치를 하나의 성능 수치로 합치지 않는다. ‘기존 금융 업무 경험자 b가 실제 응답20건을 직접 검수했고, 제품 모델은 참2·거짓2, v9는 참13·모호3으로 판정했다’고 쓸 수 있다. 현재는 ‘모든 응답 정확’, ‘실제 고객 환경 배포’, ‘전체 정확도100%’, ‘모든 코드 독립 작성’, ‘사용 시간 몇% 단축’을 주장할 수 없다.
