## 새 생성20건과 자동 검사

R01~R04는 이번 실제 MCP 실행 결과로 생성했다. R05~R20은 v9에서 사용했던 저장 도구 결과로 **새 설명을 생성**했다. 과거 모델 문장을 재생한 것이 아니다. 이16건은 이전 GPT-5.4 mini에서 제품 GPT-4.1 mini로 모델도 달라져 프롬프트만의 효과를 분리할 수 없다. 모두 수정에 사용한 개발 사례이며 새 독립 평가셋이 아니다. 이 배치에서 공식 PDF를 새로 파싱하지 않았다.

구조 필드와 근거 ID는 모두 정확히 일치했다. 실행 당시 전체 제품 검사를 통과한 사례는 **R02·R08·R10·R14, 총4/20**이다. 금액·기간·범위·출처를 정해진 문장 그대로 출력해야 하는 검사는 표현이 다른 문장도 차단한다. ‘자동 통과율20%’를 ‘설명 정확도20%’로 바꾸지 않는다.

실패 검사별 건수는 중복 집계다: 필수 근거 문장 형식12, 내부 코드 노출6, 근거 부재 표현1, % 표시2, 증감률 부호 검사3, 보류 근거 문장2.

AI가 원응답을 읽고 확인한 주요 한계는 다음과 같다. 이는 b의 새 사람 판정이 아니다.

- **R02 — 자동 통과에도 남은 문제:** ‘도구 실행 이력에 따르면 … 시작 월일 또한 달라서’라고 서술한 뒤 별도 재계산이라는 안내도 붙였다. compare()는 개월 수가 다르면 후속 YoY 날짜 조건을 실행하지 않으므로, 안내 문장을 복사했다고 앞의 실행 이력 주장이 정당화되지 않는다.
- **R01·R04 등 — 형식 차단:** 근거 문장에 조사를 붙이거나 문서명을 다른 문장에 쓰면 필수 문자열 검사에서 차단된다. 이 사실만으로 금융 수치가 틀렸다고 판단할 수 없다.
- **R09 — 부정 대상 구분:** 잘못된 초안에 ‘근거가 없습니다’라고 한 문장을 실제 근거 전체가 없다는 주장으로 검사했다. 이 구분은 아직 검사에 반영하지 않았다.
- **R17·R18 — 부호와 감소 크기:** ‘29.1445% 감소’, ‘20.5146% 감소’는 음수 증감률을 올바르게 풀어 쓸 수 있는데 기존 검사는 양수와 음수를 그대로 비교해 차단했다.
- **R13 — 지표 이름:** 전년 동분기 증감률을 ‘연평균 성장률’이라고 표현했다. **R12**는 계산값6.7916을 한 번은 % 없이 쓰고 뒤에서 %를 붙였다.

## 새 호출 없이 보완한 검사 — 동일 원응답 재생

위 실호출 이후 `explanation_guards.py`와 새 회귀 테스트7개를 보완했다. 원응답·실행 당시 판정·승인 freeze는 수정하지 않았고 새 모델 호출도 하지 않았다.

- 명시적인 ‘감소’ 크기와 음수 증감률의 대응을 허용하되, 잘못된 방향·다른 숫자·‘감소하지 않았다’는 부정문·명시적 양수 부호의 감소 표현은 보류한다.
- 별도 진단을 ‘도구 실행 이력에 따르면’이라고 주장하면 뒤에 올바른 안내를 붙였어도 차단한다.
- 분기/전년 동기 증감률을 연평균/CAGR로 명명하는 표현을 차단한다. ‘CAGR이 아니다’라는 명시적 부정은 허용하고, 뒤에 별도 긍정 주장이 이어지면 차단한다.

[동일20건의 후속 재생](../artifacts/model-completion-live-20261112/offline-followup/replay.json)은 **R08·R10·R14·R18, 총4/20 통과**다. R02는 추가 차단되고 R18의 부호 오탐이 해소됐다. 총 통과 건수는 그대로이며, 모델 생성 성능 향상을 뜻하지 않는다. 정확한 필수 문장 요구와 R09의 부정 대상 구분 등 한계도 남는다. 임의 자유 문장의 모든 의미를 자동 검증하는 파서는 아니다.

독립 AI 코드 리뷰에서 새 감소 표현의 부정문 처리와 연평균 지표 부정문의 오탐을 추가 발견해 수정했다. [중간 실패·최종 테스트](../artifacts/model-completion-live-20261112/offline-followup/)를 보존한다. 코드 리뷰와 합성 테스트를 사람 검수로 세지 않는다.
