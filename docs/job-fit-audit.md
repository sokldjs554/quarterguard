## 수치의 해석

[검색 평가](../artifacts/evaluation.json)에서 고정 길이 word 검색의 Recall@1은 8.33%, 셀 word와 문맥 필터를 포함한 혼합 구성은 100%, BGE-small은 44.44%, MiniLM은 47.22%다. 이는 **템플릿으로 생성한 개발 회귀 질의 36개**에서 나온 값이다. 이 2024 회귀셋에는 사람/전문가 검수나 튜닝과 독립된 분할이 없으므로 일반 금융 검색 정확도 100% 또는 특정 모델의 일반적 우월성으로 표현할 수 없다. 업무 8개 성공도 같은 제한이 있다.

[OpenAI 원본 기록](../artifacts/live-openai.json)은 commit `738357883f014e2c010a008145c18be66ede702c`, [Actions run 40820498010](https://github.com/sokldjs554/quarterguard/actions/runs/40820498010)의 4회 호출, 입력 2,576·출력 438 tokens를 보존한다. 도구 결과에 대한 설명 생성이며 LLM 자율 계획은 아니다. 누적 차감 응답의 “3분기 개별 매출” 표현에는 연결/별도 혼동 여지가 있다는 기존 한계도 유지한다.

[DART 기록](../artifacts/live-dart.json)은 같은 commit의 [Actions run 40820560140](https://github.com/sokldjs554/quarterguard/actions/runs/40820560140)에서 4회 조회, 16개 금액 exact match다. 반기/3분기, CFS/OFS, 매출/영업이익, 분기/누적 조합만 대조했다. 기존 기록을 재검토했으며 이번 검토에서 유료 모델 API나 DART를 재호출하지 않았다. 두 기록의 facts SHA-256은 현재 저장소·공개 평가의 `d3a7074f9f1ef0745aa04a9586833b1d1f2bf188102ef66fdb6f315b73425969`와 일치한다.

## 추가된 2025 문서 평가

[새 문서 평가](heldout-evaluation.md)는 기존 파이프라인을 동결한 뒤 공식 2025 보고서 2개·64개 숫자·40개 사례의 최초 기준선을 기록했다. 최초 실행 결과는 보존했고, 오류를 확인한 뒤 출처 검증을 수정한 결과는 별도 회귀 실험이다. 이는 이전에 전혀 없던 새 문서 검증 근거를 추가하지만, AI가 작성하고 스크립트가 대조한 정답이며 독립 전문가 검수셋은 아니다.

최초 기준선에서 원문 파싱은 0/4, fixture 보조 검색은 5/10(통제 질의 5/5, 자연어 0/5), 계산 8/8, 문맥 10/10, 인용 5/8이었다. 수정 후 인용은 8/8이 되었고 정본의 정규화 금액을 대조해 동등한 단위 표현을 허용하므로 문맥은 10/10이다. 원문 파싱·자연어 검색 실패는 남았다. 이 결과를 합쳐 하나의 정확도로 광고하거나 PDF에서 답까지 성공한 결과로 표현할 수 없다. 2025 코퍼스는 공개 2024 작업지에 자동 편입되지 않았다.

공식 PDF에서 발견한 순이익 행과 다른 합계의 불일치도 정답을 임의 수정하지 않고 보존했다. AI·복수 추출기 대조까지 이루어졌으나 발행사 정정이나 사람의 최종 판정은 확인하지 않았다. 이 실패 공개와 재평가 구분은 공고의 평가·디버깅 요구에 더 직접적인 근거가 된다.

## 직접 HTTPS 브라우저 검사의 한계

이번 환경에서 Chromium 154가 공개 URL로 직접 접속한 결과는 PC 1440×1000와 모바일 에뮬레이션 390×844 모두 `net::ERR_CERT_AUTHORITY_INVALID`였다. 기본 TLS 검증을 사용한 httpx의 공개 `/health`, `/api/evaluation`과 채용 공고 요청은 HTTP 200이었다. HTTP 클라이언트 성공은 브라우저 성공을 의미하지 않는다.

환경이 제공한 공개 CA(`/usr/local/share/ca-certificates/environment-proxy-ca.crt`)를 **격리한 Firefox NSS profile**에만 신뢰 루트로 등록하여 대안을 시도했다. 전역 신뢰 저장소와 HOME은 변경하지 않았다. Firefox 153은 페이지 접속 전에 `RenderCompositorSWGL failed mapping default framebuffer, no dt`와 `BrowserType.launch_persistent_context: Timeout 30000ms exceeded`로 종료했다. Chromium 격리 NSS mount 시도도 `bwrap: setting up uid map: Read-only file system`로 실행되지 않았다. 인증서 검증 비활성화·인증서 오류 무시·유료 TinyFish 호출은 사용하지 않았다.

따라서 **이 환경의 직접 HTTPS PC/모바일 브라우저 검증은 완료되지 않았다.** 이후 검증된 HTTPS 요청을 중계한 localhost 브라우저 검사는 별도의 결과로 표시해야 하며 직접 HTTPS 검사의 성공으로 대체하면 안 된다. 개별 시도 기록은 로컬 Git 제외 경로 `work/https-audit/chromium-direct-attempt.json`, `browser-attempt-3.log`에 있다. 최종 배포 후 확인 범위와 결과는 [완료 보고서](completion-report.md)를 따른다.

## 이번 검토 시작 시 공개 버전

GitHub main, Render의 live 배포 `dep-dbhgnfgu01pc73a9esc0`, 공개 `/health.commit` 모두 `14b2159cb22d350f30c2a259a2469cfe579058be`였다. Render는 `sokldjs554/quarterguard`의 main을 자동 배포하는 Singapore free 웹 서비스다. 이 값은 **이번 변경 이전 기준점**이며 후속 변경의 배포 완료를 의미하지 않는다. 최종 릴리스의 SHA·API/UI 버전·브라우저 결과는 배포 후 다시 확인해야 한다.
