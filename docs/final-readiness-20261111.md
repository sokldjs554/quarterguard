## 제품과 평가의 구분

- 제품 분기 작업지: 삼성2024반기·3분기192개 정본.
- 제품 새 선택 계산: SK하이닉스2024·2023공개 원문의18개 셀, 연간/연말잔액/제품비중. 사용자 질문을 자동 완성하는 범용 금융 에이전트가 아니다.
- 현대차: 원문 파싱 및 별도 격리 평가. 공개 회사 선택에 포함되지 않는다.
- v9: GPT-5.4 mini, 기존16개 개발 입력, 저장 도구 결과 재생. b의 해당 새 응답 판정 대기.
- 이번 동일 조건 평가: GPT-4.1-mini-2025-04-14, 실제 MCP→공개 payload/validator. 기존 공개 대상4개(qoq-revenue, ytd-trap, no-evidence, reconcile-revenue). 새 독립 사례가 아니다.
- 제한형 플래너: 이미 명시한 두 검색 문장과 비교 방식 안에서 검색·조회·비교를 모델이 선택하도록 하는 별도 실험. 순수 자연어에서 누락된 조건을 추측하거나 임의 도구·네트워크·쓰기 작업을 실행하지 않는다. 모델에게 정답 ID·금액을 미리 주지 않는다.

## 공개 서버 소량 측정

수정한 측정 스크립트의5회씩, 총20회 순차 요청은 전부 성공했다. TLS 검증을 켠 HTTPS클라이언트이며 클라우드 네트워크/프록시 시간이 포함된다.

첫 측정은 health에서30초 시간초과가 있었다. 같은 시간대 Render의 프로세스 시작 로그가 확인됐지만 플랫폼 시작·네트워크 시간을 분리 측정한 것은 아니다. 접속 문제가 완전히 해결됐다고 주장하지 않는다.

첫 검색 측정에는 검사 코드가 `q` 대신 `query`를 보내는 오류가 있어10회 빈 결과가 나왔다. 이 결과를 보존하고 검사 코드를 수정해 새 경로에서 재측정했다. 검색 품질 실패나 정확도 개선으로 세지 않는다.

첫 배치40요청·수정 배치20요청을 구분한다.5개 표본의 nearest-rank p95는 최대값이며, 안정적인 모집단 추정·고객 부하·가용성 SLA가 아니다. 비용을 늘리는 서비스 변경은 하지 않았다.

## 사람 참여·실호출 게이트

[한 번에 전달할 최종 검수 자료](validation-kit/final-round-20261111.md): v9설명16건, 새SK사용과제, 새 사람이 직접 작성할6~8질문, 새 제품 모델 응답 검수 칸을 구분했다. 빈 양식은 실제 참여가 아니다. 기존 외부 참여자는 계속2명이며 본인의 사례 작성은 별도다.

유료 계약: GPT-4.1-mini-2025-04-14, 설명4회 + 플래너4과제(과제당최대6회), 총최대28회·재시도0. 회당 전체요청UTF8바이트+1024로 사전 제한16000토큰 상당, 출력700. 입력$0.40/출력$1.60 per1M 기준 최대추정$0.21056, 예산$0.22(세금·환율 제외). 청구액 미조회. [공식 단가](https://developers.openai.com/api/docs/models/gpt-4.1-mini)를2026-11-11확인했다.

실제 유료 전송은 지정된 main 브랜치의 단일 Actions workflow로 제한한다. 로컬 실행은 dry 또는 주입된 테스트 전송만 허용한다. 계약 예약은 출력경로가 달라도 중복을 거부한다. Actions는 이전dispatch·rerun을 키노출 전에 차단한다. 각 시도는 전송 전에 기록하고 실패도 지우지 않는다. Workflow artifact는30일이므로 실행 후 성공/실패 원본을 저장소에 별도 보존해야 한다. 현재 실제호출0회이며 새 비용승인 전 실행하지 않는다.
