`explanation_context.py`의 안내와 모델 지침을 바꾸고, `explanation_guards.py`에서 설명 문장의 두 내부 코드 노출을 거부한다. 구조 필드·문제 코드·근거 ID는 바꾸지 않는다. 정규식은 한국어가 붙은 `SEARCH_EMPTY입니다`도 검사한다. 원응답을 교정해서 새 응답처럼 저장하지 않는다. 독립 재계산 진단과 실제 도구 조건 실행 이력을 구분하는 작성자의 코드는 유지한다.

표현 검사는 특정 코드의 노출만 찾는다. 금융 의미 전체를 보장하지 않으며 잘못된 한국어 설명을 모두 잡는 것은 아니다.

## 추가 검색 평가

실행 전에 [새 질의·예상 판정](../data/plain-language-v8-20261111/new-queries.json)을 작성·동결했다. AI가 기존 정본 ID와 명시 조건으로 정답을 작성했으며 새 사람 검수는 없다. 검색 코드와 질의는 첫 결과를 본 뒤 조정하지 않았다.

- 삼성 2022·2021, 현대 2025·2024가 포함된 기존 32개 정본을 재사용했다. 한·영 질의 8건의 **새 문구 평가**이며 새로운 문서 독립 평가가 아니다.
- 답변 조건을 갖춘 4건: 예상 정본의 Top1 일치 4/4, Recall@5 4/4, MRR 1.0. 정답이 각 1개인 작은 표본이다.
- 조건 누락·범위 충돌 3건: 추가 확인 필요. USD 정본 없는 1건: 검색 결과 없음. 예상 판정 4/4.
- 합계 8/8. 검색 API의 `answer_status`는 계속 `not_verified`다. 검색 후보 일치가 최종 금융 검증 성공이라는 뜻은 아니다.
- 첫 순차 실행 지연 중앙값 1.356ms, 최대 7.318ms. 로컬 인덱스 생성 시간·네트워크 제외, 반복 부하 시험 아님.
- 기존 PDF 처리 결과를 **fixture로 불러온 평가**다. 이번 실행에서 PDF를 새로 열거나 파싱하지 않았다. 결과에 수치·페이지·행·열을 함께 저장했지만 독립적인 원문 재검수를 수행한 것은 아니다.

[첫 실행 결과](../artifacts/plain-language-v8-20261111/new-query-first.json)와 이후 재현 실행은 분리했다. 검색 방식·청킹·임베딩·리랭커를 새로 비교한 실험도 아니다.
