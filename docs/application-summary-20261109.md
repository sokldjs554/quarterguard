## 이번 후속 작업

- **현대자동차 원문 파서 지원 완료(검증한 표 구조):** [파서·개발 회귀](hyundai-parser-20261109.md), [별도 문서 평가](hyundai-holdout-20261109.md). 기존2023 혼합 평가가 4/5표·64/80셀에서 5/5표·80/80셀로 바뀌었다. 별도2024 첫 실행은 실패했고 수정 후16/16셀·질의7/8이다. 다시 동결한2025 첫 실행은16/16셀·질의8/8·계산2/2다. 2024 수정 후 결과는 보류셋 첫 성공으로 표현하지 않는다. 2025 비교연도8개 셀은2024 자료와 겹친다.
- **제품 범위:** 현대차 파싱·평가용 검색/인용/계산을 지원하며 공개 데모의 정본·기업 선택에는 등록하지 않았다. 공개 데모에서 현대차를 사용할 수 있다고 주장하지 않는다. 원문 PDF에서 추출한 단계와 준비한 수치를 넣은 fixture 단계는 각 보고서에서 구분한다. 자연어2024 질의1개는 기간 종류 확인 필요로 남았다.
- [새 LLM 출력 평가](llm-evaluation-20261109.md): 승인된 GPT-5.4 mini 고정버전, 최대8회, 입력 사전제한6000·출력700, 예산$0.07(세금·환율 제외). 기존 Actions 키 재사용 승인. 실제 호출·결과·사용량은 실행 후 따로 기재한다.
- 사람 정답 검수: [셀8개·질의4개 안내](validation-kit/source-gold-review-20261109.md), [빈 기록지](validation-kit/source-gold-review-sheet-20261109.md). 현재 미수행이며 b의 앱 사용 결과로 대신하지 않는다.

## 지원서용 문장

> AI 코딩 도구를 활용해 금융 문서의 원문 근거와 비교 조건을 대조하는 QuarterGuard를 개발했습니다. 알려진 새 연도 파싱 실패를 보완하고 원문 PDF 평가와 fixture 평가를 구분했으며, 실제 리랭커가 성능을 악화시킨 결과도 공개했습니다. 직접 기간 비교와 DART 단위·중복 후보 방어 코드를 읽고 테스트 5개를 보강·실행·커밋했습니다. 금융 분야 지인의 공개 자료 검토 의견을 반영해 비교 조건 표시와 결과 복귀 동작을 개선했고, 같은 참여자의 후속 확인을 기록했습니다.

본인 직접 실행5개는 기간2개와 DART3개를 합친 것이며, 한 번에5개를 실행한 로그라는 뜻은 아니다. 전체147개는 최신 통합에서 AI가 실행한 회귀 결과다. 본인이 과거 보고한 전체143개와 시점·주체를 구분한다.

## 아직 주장할 수 없는 내용

금융기관 고객 환경 배포, 독립 전문가의 평가셋 전체 검수, 모든 기업·문서 지원, LLM 문장 전체 정확성 보장, 자율 도구 계획, 리랭킹의 일반적 성능 향상, 사람의 작업시간 단축률, 독립 개발·AI 도움 없음.

## 사용자님이 진행할 부분

1. 데모 접속: 실제 날짜·기기·브라우저, 최초 접속/재접속, 정상 비교·보류·복귀 결과를 기록한다. 접속 실패를 숨기지 않으며 AI가 대신 수행한 것으로 적지 않는다.
2. 사람 검수: 위 빈 기록지를 전달하고 실제 작성본을 받은 후 공개할 요약의 동의를 확인한다. 실제 회사 환경이 생기면 [접근·자료·배포 범위 확인표](validation-kit/customer-access-checklist.md)를 먼저 확인한다.
