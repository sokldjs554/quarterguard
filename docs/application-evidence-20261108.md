# 지원서에 연결할 근거 — 2026-11-08

이 문서는 과거 평가를 새 실행으로 바꾸지 않고, 이번에 확인된 개인 테스트·공개 반영·참여 의견을 연결한다. 최신 배포 상태는 `/health`와 Render 배포 커밋을 다시 확인한다.

## 짧은 소개

공식 금융 문서의 기간·연결 범위·통화·단위를 확인하고, 조건이 맞지 않으면 계산을 보류하는 QuarterGuard를 개발했습니다. 원문 파싱·검색·MCP 도구 실행과 실패 사례를 공개하고, 직접 실행한 QoQ/YoY 회귀 테스트를 추가했습니다. 대학생 1명의 시연 피드백을 화면에 반영하고, 금융회사 기업 재무분석·여신심사 지원 경력 3년인 지인에게 문서·코드 검토 의견을 받아 후속 검토 과제를 정리했습니다.

## 상세 설명

AI 코딩 도구를 활용해 금융 문서의 수치와 출처를 대조하는 공개 데모를 개발했습니다. 2025년 문서에서 연도 헤더 차이로 표 파싱이 0/4였던 실패를 보존하고, 헤더·기간·단위·행·열 검사를 보완한 뒤 실제 PDF에서 4/4 표와 동결 정답 64/64 일치를 확인한 평가를 공개했습니다. 다른 기업의 미지원 표와 리랭커의 성능 하락도 함께 기록했습니다.

저는 기간 비교 코드를 직접 검토하고, 같은 3개월 자료라도 인접하지 않으면 QoQ를 차단하고 전년 동기이면 YoY를 허용하는 테스트 2개를 저장·실행·커밋했습니다. macOS 11.7.11 / Python 3.12.8에서 전체 143개 테스트 통과를 확인했고, 변경은 PR #14로 공개됐습니다. 대학생 1명에게 개발자 시연을 진행하고 원문 열람과 조건 표시의 불편에 대한 의견을 받았습니다. 이후 금융회사 기업 재무분석·여신심사 지원 경력 3년인 친구에게 공개 문서와 비교·DART 대조 코드의 검토 의견을 받았습니다. 비교 기준의 가독성, 보류 이후 조치, 결과 재확인을 후속 과제로 정리했습니다. 이 기록은 금융기관 고객 환경 배포나 원문 수치의 독립 전문 검수 결과가 아닙니다.
