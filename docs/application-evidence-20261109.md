# 지원 근거 후속 — 2026-11-09 KST

[이전 상세 근거](application-evidence-20261108.md)의 개인 테스트·파싱·검색·LLM/MCP 범위는 그대로 보존한다. 이번에 추가된 것은 금융 분야 지인 b의 **개선 후 모바일 직접 재확인 보고**이며, 새 성능 평가나 고객 환경 배포가 아니다.

## 지원서에 쓸 수 있는 문장

> 금융회사에서 기업 재무분석·여신심사를 지원하는 경력 3년의 지인에게 공개 자료 기반 데모 검토를 요청했습니다. 금액 가까이에서 비교 조건을 읽고 싶다는 의견을 반영해 모바일 A/B 금액 아래 실제 기간·연결 범위·단위를 표시했습니다. 같은 참여자가 변경된 화면에서 조건을 설명하고, 누적·별도 변경에 따른 계산 보류와 정상 복구를 추가 도움 없이 수행했다고 보고했습니다. 수정 버튼까지 스크롤해야 한다는 남은 불편도 함께 기록했습니다.

근거: [개선 전 직접 수행](validation-kit/session-b-task-followup-20261108.md) → [AI 도구를 활용한 UI 변경·자동 검사](mobile-context-followup-20261108.md) → [개선 후 b의 재확인](validation-kit/session-b-mobile-recheck-received-20261109.md). 진행자는 이번 기록의 수행자와 공개 확인을 명시했다.

위 문장은 금융기관의 공식 고객 검증·회사 승인·배포를 주장하지 않는다. 시간 단축은 측정하지 않았다. UI 구현과 자동 검사는 AI 도움을 받은 작업이며, 지원자의 직접 코드 검토·테스트 기록은 [별도 근거](code-review-kit/review-20261108.md)로 구분한다.

## 운영 보완과 한계

[무료 데모 기동 경로 수정](startup-availability-20261109.md)에서 기본 화면이 검색 라이브러리 로딩을 기다리지 않도록 변경하고 회귀 테스트를 추가했다. Python 144개 통과는 이번 AI 실행이며 지원자가 직접 실행한 과거 143개 기록을 대체하지 않는다. 초기 로딩의 로컬 측정 개선과 Render 자동 재기동 장애 해결은 별개다. 유료 요금제 변경이나 새 유료 API 호출은 하지 않았다.

## 남은 불편에 대한 후속 수정

이 재확인에서 남은 스크롤 불편을 반영해 [비교표 위 기간·범위 설정 이동 버튼](recovery-shortcuts-20261109.md)을 추가하고 자동 검사했다. b의 위 재확인은 이 버튼 추가 **전** 결과다. 당시에는 버튼 변경 후의 사람 재확인 기록이 없었다. 이후 직접 확인 의견은 다음 절에 별도로 추가했으며, 시간 단축은 여전히 측정하지 않았다. 각 변경 전 의견을 해당 변경 후 성공 결과로 재사용하지 않는다.

## 표 위 설정 이동 버튼의 후속 의견

같은 참여자 b가 해당 버튼을 직접 확인한 뒤 수정 위치를 찾는 불편이 줄었다고 보고했다. 설정에서 결과로 돌아오는 동작, 문구, 세로 공간에 대한 남은 의견도 [별도 공개 기록](validation-kit/session-b-recovery-feedback-received-20261109.md)에 보존했다. 이를 바탕으로 [설정 닫고 결과 보기](settings-return-20261109.md) 버튼을 추가하고 자동 검사했다. 이후 같은 참여자는 [이번 복구 흐름에서 막힌 부분이 없었다고 보고](validation-kit/session-b-settings-return-received-20261109.md)했고 진행자는 직접 확인과 공개 동의를 확인했다. 항목별 실행 출력이나 소요시간은 새로 제공되지 않았다. 위 각 단계는 한 참가자의 후속 기록이며 참여자 수나 독립 금융 검수 횟수로 늘려 세지 않는다.

## 설정 복귀 개선까지 포함한 지원서 문장

> 금융 분야 지인의 공개 자료 기반 검토에서 조건 수정 후 결과로 돌아가기 불편하다는 의견을 받았습니다. AI 도구를 활용해 설정 가까이에 결과 복귀 버튼을 추가하고 자동 검사했습니다. 같은 참여자는 변경 후 이번 복구 흐름에서 막힌 부분이 없었다고 보고했습니다.

이 문장은 위 익명 후속 기록 범위이며, 독립 전문가 인증이나 작업시간 단축 수치로 표현하지 않는다.
