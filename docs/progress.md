# 진행 기록

- 조사: 공고 TinyFish 직접 조회 성공. 주요 요구 일치. 원문에 스택/복지 추가. 채용 중간 단계는 추출에서 확인되지 않음.
- GitHub: network 권한을 명시한 gh api user 성공. sk/family 이름 조회에서는 일치 저장소 없음; 식별 추측 금지.
- 결정: 사용자에게 주제 선정과 실행 권한이 이미 부여되어 별도 설계 승인 요청하지 않음.
- 결정: Python 실행이 필요한 공개 데모는 Sites Worker 대신 Render 사용; 대상 선택 대기.
- 결정: 생성형 모델 없는 규칙 기반 MCP 검증 흐름을 기본값으로 하며 이를 LLM 에이전트라고 표현하지 않음. 신경망 검색은 별도 실험.
- 파서: 실제 PDF 2건, 4개 표, 192개 수치 추출 완료. 원문 미배포.
- MCP: 실제 stdio handshake·도구 호출 통과. 샌드박스 네트워크 권한 필요는 실행 환경 문제로 분리.
- 평가: 36개 템플릿 질의/6개 검색 구성(신경망 2종 포함), 업무 8개 측정. 정답 오기 원본 보존.
- 브라우저: 로컬 PC/모바일 21개 흐름 확인; 오류/빈 결과/재시도 포함. 리뷰 수정 후 재검증 예정.
- 독립 AI 리뷰: 5개 중요한 발견을 모두 회귀 테스트로 재현·수정; 전체 38 tests green.
- 결정: USD 참고 환산액은 환산율이 같아도 계산 차단. 표시·검색은 제공하며 정상 외화 회계에 대한 일반화를 피함.
- 결정: 공개 검색은 삼성전자 명시 + 정해진 금융 용어를 지원. 미지 기업/조건을 추측하지 않음.
- 리뷰 범위 제외 항목: 배포/브라우저는 직접 검증 진행; DART live는 키 없음, 모델 clean-machine 반복 다운로드는 미검증으로 보고. README/산출물 검사는 후속 완료.
