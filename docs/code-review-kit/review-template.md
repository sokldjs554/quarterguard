검토자 본인이 실제 읽고 설명하고 실행한 내용을 기록한다. AI가 제공한 설명·예상값은 참고자료다. 본인이 그대로 붙여 넣었다면 독립 설명이나 직접 발견으로 표기하지 않는다. 날짜·완료·수정·재검증을 자동으로 채우지 않는다.

| --- | --- |
| 검토자 역할 / 직접 수행 확인 | NOT_PERFORMED |
| 수행 일시·환경·Python 버전 | NOT_PERFORMED |
| 검토한 commit / 미커밋 변경 범위 | NOT_PERFORMED |
| 읽은 파일·함수·테스트 | NOT_PERFORMED |
| 실행한 명령·출력의 비공개 또는 공개 근거 경로 | NOT_PERFORMED |

다음 표를 세 주제별로 복사해서 작성한다.

완료된 주제만 완료로 표시한다. 검토만 했다면 “코드를 읽고 정상·거부 입력을 직접 재실행했다”로 쓰며 수정 경험으로 확대하지 않는다. 실제 사용자 피드백을 수정 원인으로 쓰려면 별도의 동의된 세션 기록과 해당 변경의 연결 근거가 필요하다.
