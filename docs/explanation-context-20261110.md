# 설명의 단위·검색 범위·인용 위치 보완 — 2026-11-10 KST

같은 참여자 b의 [후속 검수](validation-kit/session-b-image-llm-received-20261110.md)에서 실제 응답8개 중 참5·모호3 판정과 통화/단위 주석을 받았다. 이를 공개 데모의 향후 설명 생성 지침과 근거 표시 경로에 반영했다. **새 LLM 호출·출력·사람 재검수는 없다.** 기존8개 응답의 모호 판정을 통과로 변경하지 않는다.

## 변경과 설계 선택

프롬프트만 바꾸면 모델의 준수 여부를 추가 실호출로 확인해야 하고, 기존 응답을 규칙으로 고쳐 표시하면 실제 모델 출력과 혼동할 수 있다. 따라서 **생성 지침 보완 + 도구 결과에서 별도 구성한 단위·출처 안내**를 선택했다. 생성된 원문은 그대로 두며 안내의 출처와 역할을 화면에서 구분한다. 구현 선택은 AI가 수행했으며 사용자가 코드를 직접 수정했다고 기록하지 않는다.

## 실제 표시 예

아래는 LLM이 새로 생성한 설명이 아니라 도구 결과로 구성하는 근거 안내의 예다.

> 79,098,731 백만 원 · 통화 KRW · 2024-07-01 ~ 2024-09-30 · 3개월 · 연결. 근거: Samsung Electronics 2024 3Q Interim Business Report, PDF p.34, Revenue / 2024 Q KRW.

> 해당 검색 범위에서 근거를 확인할 수 없습니다. 기업의 실적 자체가 없다는 뜻은 아닙니다. 검색 조건과 수집 범위를 확인하세요.

원문 링크에는 `#page=34`처럼 PDF쪽수를 포함한다. 행·열 코드는 정본의 위치 표현이며, 원문의 시각적 열 배치까지 새로 검증한 것은 아니다. 공개 제품은 기존 삼성전자 정본 범위로 유지한다.

## 완료 범위와 남은 확인

단위·검색 범위 안내와 근거 링크, 향후 공개 생성 지침 변경 및 오프라인 검증은 완료했다. **새 프롬프트의 실호출 효과와 개선 후 사람 검수는 미완료**다. 자동검사8/8을 모호3건 해소나 모델 정확도 향상으로 주장할 수 없다. 실제 재생성 평가가 필요하면 모델·건수·토큰 상한·최대 비용을 새로 승인받아야 한다. API 사용을 위한 기존 공개 서버 승인/원장 조건도 완화하지 않았다.

사람에게 다음으로 확인할 내용: 금액과 표시 단위를 함께 읽을 수 있는지, 검색 실패를 실적 부재로 해석하지 않는지, 문서·페이지 링크에서 해당 행·열을 찾을 수 있는지. 아직 누군가 이 변경을 사용하거나 확인했다고 기록하지 않는다. 공개 배포 상태는 이 변경 PR의 CI와 Render 배포 커밋을 별도로 확인한다.

지원서에는 “검수 의견을 바탕으로 통화·표시 단위 구분, 검색 범위의 한정, 문서·페이지 링크를 보완하고 자동 회귀와 응답 재생으로 확인했다”고 쓸 수 있다. “수정한 LLM 설명을 현업 검수에서 모두 통과했다”는 표현은 아직 사용할 수 없다.
