# 채용 요구사항과 검증 근거

|공고·요청 요구|구현·검증|범위/한계|
|---|---|---|
|Python 단독 완성 경험|FastAPI·파서·계산·검색·MCP·평가·테스트|AI 코딩 도구로 작성; 본인이 단독 수작업 작성했다고 주장 불가|
|문제 정의와 지표|분기/누적·범위·단위 혼동; Recall/MRR·상태·수치·인용 exact match|작은 템플릿 회귀셋; 고객 지표 아님|
|API 문서 학습|MCP SDK 실제 handshake와 4개 tools, 과거 DART CI 4회·16금액 + 공개 데모 4회·16금액 대조|삼성전자 2024년 반기·3분기만 검증; 기본 코퍼스 자동 병합 없음|
|금융 문서 파싱/청킹|2개 실제 PDF·4개 표·192 facts, 본문 분리, 2개 청킹|삼성전자 영문 2024 표 한정; 범용 OCR 아님|
|검색·임베딩 비교|TF-IDF word/char·혼합·2 ONNX dense, 6개 구성|신경망 재랭커 없음; 규칙 문맥 필터 적용|
|프롬프트·툴 설계|좁은 도구 schema와 설명, 규칙 기반 다단계 실행, OpenAI 설명 생성 4회|구조 필드 대조 통과; 문장 모호함 1건 기록. 프롬프트 최적화·LLM 자율 계획 미실행|
|실패 로그·수정|trace 단계별 입력/출력/latency, 실패 유형, AI 리뷰 5건 수정|무료 인스턴스 API 시도 기록은 재시작 시 초기화 가능; LLM은 지속 기록 없으면 차단|
|수치·인용 검증|Decimal, 날짜/항목/기업/범위/통화·단위, manifest·gold 대조|전문 회계 감사 또는 투자 자문 아님|
|MCP|실제 mcp SDK stdio 4개 tools|별도 검증에서는 실제 MCP 결과에 LLM 설명 추가; 기본 웹 데모는 LLM 호출 없음|
|평가 자동화|개발 검색 36개·업무 8개 + 2025 문서 2건/64수치/40사례 별도 평가|사람 검수·LLM-as-judge 없음; 새 파서 0/4·자연어 0/5 실패 공개|
|비용·지연|실제 검색/모델/도구 elapsed time; 별도 OpenAI 4회 입력 2,576·출력 438 tokens|청구액·인프라/CPU 총비용 및 실제 트래픽 최적화 미측정|
|Git 브랜치/PR|feature 브랜치와 PR, CI|AI 리뷰만 존재; 사람 협업 리뷰를 꾸미지 않음|
|제품 UI|채팅 없는 검증대·근거 상세·도구 기록·검색·평가|데모 데이터 읽기 전용; 임의 PDF 업로드 없음|
|API 키 없는 경험|prepared replay와 실제 Python MCP 실행|발행사 원문 PDF 링크는 외부 가용성 의존|
|첫 4주 고객 배포|개인 공개 데모로 배포 가능성 증명|실제 고객 환경/4주 프로젝트 경력을 주장할 수 없음|

단위·통합 테스트의 구체적인 목록은 tests/, 측정치는 artifacts/가 정본이다. 프로젝트 설명용 수치를 따로 만들어 표시하지 않는다.

현재 공고와의 상세 대조는 [재검토](job-fit-audit.md), 공개 API의 실제 상태와 최종 배포는 [보완 보고](completion-report.md)를 참조한다.
