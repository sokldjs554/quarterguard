# 사람 검수 이후 설명 범위 보완

기준 커밋 `eb1761975641c73c3d887e8f17c16ee62ba0df56`의 [b 검수20건](validation-kit/completion-human-review-20261112/README.md)을 개발 사례로 사용했다. 원응답, 사람 판정(참11·거짓4·모호5), 기존 실패와 입력 freeze는 변경하지 않았다. **이번 작업은 코드 수정과 저장 응답의 무료 재검증이다. 새 모델 생성·사람 검수·독립 평가가 아니다.**

## 실제 변경

- **검색 결과 없음:** `explanation_ko`를 현재 검색 범위의 근거 부재만 설명하는 고정 안내로 제한했다. JSON Schema enum과 서버 검사가 모두 같은 문장을 요구한다. 올바른 안내 뒤에 “수집된 자료 전체에 없다”는 추측을 붙인 R10도 차단한다. 설명의 다양성을 제한하는 설계이며 모델 추론 능력 향상으로 표현하지 않는다.
- **도구 판정과 독립 진단:** 모델에게 보내는 `build_generation_context()`는 보고된 문제 코드에 대한 안내만 담는다. 별도 재계산의 `failed_conditions`는 모델 입력에서 제외했다. 기존 `build_context()`의 진단은 검토용 문맥에 보존한다. 원래 `compare()` 판정이나 실행 이력을 수정하지 않았다.
- **조건 실행 이력 주장:** 시작 월·일 차이를 도구가 실행한 보류 이유로 돌리거나 독립 재계산이 비교를 보류했다고 쓰는 공개 실패 패턴을 차단한다. 뒤에 올바른 안내를 붙여도 별도 잘못된 주장은 남는다.
- **회사 비교 범위:** 회사 불일치는 이 도구의 같은 회사 성장률 계산 제한이라고 명시한다. 모든 기업 간 직접 비교가 불가능하다는 일반화 패턴을 차단한다. 누적 차감에는 성장률이라는 이름을 붙이지 않도록 계산 종류를 구분한다.
- **기존 방어 유지:** 수치·표시 단위·근거·방향·% 누락·연평균/CAGR 오명명 검사와 실패 응답 비노출을 유지한다. 검사·문맥 파일의 해시가 캐시 키에 포함되어 이전 응답 캐시를 새 검사 결과로 재사용하지 않는다.

## 같은 원응답20건의 전후 비교

전후 기준은 실제 생성 당시 통과4건이 아니라, 직전 무료 후속 검사(`635656f` 코드)의 통과4건과 이번 검사다. [상세 JSON](../artifacts/explanation-boundaries-20261112/replay-final.json)에 사례별 검사와 파일 해시를 기록했다.

|기준|자동 통과|통과한 사람 판정|보류한 사람 판정|
|---|---:|---|---|
|직전 후속 검사|4/20|참3·모호1|참8·거짓4·모호4|
|이번 후속 검사|3/20|참3|참8·거짓4·모호5|

통과 사례는 R08·R14·R18이다. **사람 거짓4건·모호5건이 모두 보류되며, 기존에 통과하던 R10을 추가 차단했다.** 이는 같은 개발 표본에서의 차단 확인이지 새로운 설명 정확도100%가 아니다. 사람 ‘참’11건 중8건도 보류한다. 정확한 필수 근거 문장 형식 때문에 올바른 바꿔 쓰기나 문서명 배치 차이도 통과하지 못한다. R09의 잘못된 초안에 대한 부정을 전체 근거 부재로 읽는 기존 검사 한계도 남는다.

회사 비교와 조건 귀속 검사는 공개한 한국어 패턴만 다룬다. ‘이 도구에서는 같은 회사 성장률의 직접 비교가 불가능합니다’처럼 범위를 붙인 표현도 보수적으로 보류할 수 있다. ‘모든 비교가 불가능한 것은 아닙니다’라는 명시적 부정은 허용하지만 뒤에 별도 금지 주장을 붙이면 차단한다. 모든 자연어 부정·인과관계를 이해하는 검사가 아니다.

## 검증과 보존

- 추가 회귀10개: 최초9개는 수정 전 실패를 확인했다. 독립 AI 코드 리뷰가 누적 차감을 성장률로 잘못 안내하는 회귀를 발견해 실제 `reconcile()` 입력 테스트1개를 추가했다.
- 첫 전체 실행: 371개 중 실패2·오류10·건너뜀1. 두 실패는 변경된 생성 계약을 기대값에 반영하지 못한 테스트였고, 오류10개는 길어진 프롬프트의 과거 v5 입력 상한 초과였다. 기대값을 새 계약으로 정리하고 프롬프트를 줄였다. **승인 상한을 높이거나 과거 결과를 수정하지 않았다.**
- 최종 Python372개 실행: 실패0·건너뜀1. Node26개 통과. Pydantic/Starlette 관련 환경 경고는 로그에 보존했다.
- 기존 실제 MCP 기반 규칙 실행8사례 일치, 유료 모델 호출0회. artifact의 corpus/gold 해시와 정확한 인용 대조 통과.
- [중간 실패·최종 로그](../artifacts/explanation-boundaries-20261112/)와 독립 AI 코드 리뷰 결과를 보존한다. AI 작성 테스트·코드 리뷰를 본인 독립 작성이나 b의 새 검수로 세지 않는다.

## 완료와 남은 한계
