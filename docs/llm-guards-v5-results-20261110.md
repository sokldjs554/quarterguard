## 남은 문장 문제 — AI 관찰, 사람 판정 아님

|사례|실제 원응답 일부|검토할 부분|
|---|---|---|
|period-mismatch|“해당 검색 범위에서 확인할 수 없습니다.”|앞에서 근거2개와 기간 불일치를 설명한 뒤 이 문장을 덧붙였다. 도구는 SEARCH_EMPTY가 아닌 PERIOD_MISMATCH만 보고했다. 근거 부재로 오해되는지 확인 필요. 표시 단위도 미표기.|
|citation-draft|“따라서 매출 증가율은 6.7916입니다.”|증가율의 %가 생략됐다. 앞의 “같은 보고서 기준” 표현도 서로 다른 두 보고서 출처와 함께 검토해야 한다.|
|no-evidence|“context needs review.”|한국어 설명 끝에 설명되지 않은 영어 내부 표현이 남았다.|
|scope-mismatch|“다른 분기라는 사실만으로는 보류 사유가 아닙니다.”|이전 모호함을 구분하는 문장이 생성됐다. 다만 새 b 판정 없이 ‘사람이 개선을 확인했다’고 쓰지 않는다.|

[AI 관찰 원기록](../artifacts/llm-guards-v5-20261110/ai-observations.json)을 사람 검수와 분리했다. 모델 응답을 고쳐서 공개하지 않았고 추가 호출로 좋은 응답을 골라내지 않았다.

기존 페이지 표현 규칙은 `p.34`처럼 페이지 표지가 숫자 앞에 있어야 인식한다. period-mismatch의 `PDF 34쪽`은 실제로 위치를 적었지만 규칙상 미충족으로 잡힌다. 이번 비교에서는 평가 기준을 사후 변경하지 않고6/7을 그대로 보존했다. UNBOUND_NUMBER_REQUIRES_REVIEW와 NEGATION_REQUIRES_REVIEW도 사람이 문맥을 확인하라는 경고다. LLM-as-judge 호출0회이며 금융 수치를 다른 모델의 판단 하나로 인증하지 않았다.
