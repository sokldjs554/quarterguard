# Apple 2024 Form 10-K: 새 제출7문항의 수정 전 결과

기준 커밋 `60af1fdd76a6c52154e596fdae8c0ad683edf185`. 사용자에게 받은7개 질문·답안·원문 위치를 [제출 원본 전사](../data/apple-submitted-20261112/submission.json)에 보관하고, 제품 코드를 수정하거나 Apple 자료를 등록하기 전에 [해시·질문·코드/코퍼스 고정](../artifacts/apple-first-20261112/freeze.json) 후 실제 앱의 검색 API를 실행했다.

최초 실행 당시 AI미사용 여부는 확인 대기여서 동결 원본에는 null로 기록했다. 이후 작성자인 프로젝트 본인이 **“본인이 AI 없이 직접 작성”**이라고 확인했다. [후속 작성 출처 확인](../data/apple-submitted-20261112/authorship-confirmation.json)에 원문 답변과 제출 해시를 추가하고, 동결 제출·최초 실행 기록은 변경하지 않았다. 사용자 진술에 근거한 AI미사용 직접 작성7문항이며, 새 외부 참여자나 독립 전문가 검수로 세지 않는다. 질문·답안의 사람 작성과 이후 AI 원문 대조는 별개다.

## SEC 원문 별도 대조

[사용자 제공 공식 SEC 공시](https://www.sec.gov/Archives/edgar/data/320193/000032019324000123/aapl-20240928.htm)는 **HTML**이다.29·22·33·40은 문서에 인쇄된 쪽수다. PDF파일·PDF뷰어 쪽수로 기록하지 않는다. TLS검증을 켜고 실제 HTML을 받아 평가 전용 스크립트로 표·열·셀을 확인했다. 원문 전체는 로컬 work에만 보관하고 URL·해시·선택된 수치의 위치를 공개한다.

질문에 사용된 고유 수치19개가 제출값과 일치했다. 단위는 **백만 미국 달러(USD million)**이며, 원본 표에는 공통 단위 머리말이 없으므로 이 설명을 별도로 추가한다. 제품 지원이나 새 제품 파서 성능으로 세지 않는다. 현재 제품의 PDF파싱 실행은0건이며 이 감사는 HTML 대조다.

[표·행·연도열·인쇄쪽·XBRL 문맥/단위·검산](../artifacts/apple-first-20261112/source-audit.json).19셀 중 지역표4셀은 inline XBRL 태그가 없는 표시용 HTML이라 실제 colspan/연도열로 읽었고, 나머지는 표시값과 inline XBRL 문맥을 대조했다. 첫 감사 시 지역표도 태그가 있다고 가정해 중단된 기록과 수정된 감사 방법을 별도로 보존했다. 제품의 최초0/7결과에는 영향이 없다.

## 재현

기존 첫 결과를 덮어쓰지 않고 새 경로에 재현한다. 재현 결과는 최초 실행으로 표시하지 않는다. 원문 HTML은 공식URL에서 내려받아 저장하고 고정 해시가 일치해야 감사할 수 있다. 감사 스크립트는 평가용 lxml이 필요하며 제품 의존성에 새로 추가하지 않았다.

```bash
python scripts/evaluations/apple_first_20261112.py --output work/apple-reproduction-new
python scripts/evaluations/apple_source_audit_20261112.py --html work/apple-first/sec-response.html --output work/apple-audit-new.json
```

검증 기록: 입력 평가 도구 기존 테스트6개 통과, 원본 artifact 일관성 검사 통과. 별도 재현의7개 응답과19셀 감사 결과가 최초 기록과 일치했고, 독립 AI 검토에서 중대한 지적은 없었다. 기존 원기록670개는 변경하지 않았다. 사람 검수로 세지 않는다.
