# v8 사람 검수 후 코드 보완 — 무료 회귀와 추가 문장 평가

기준 커밋 `7366cd4a8e27d2023fe03fcc731c2bea64b26301`. 코드 수정·테스트·합성 문장 작성·재생 실행은 AI가 수행했다. 기존 b의 실제16건 검수와 구분한다. **새 유료 호출0회·새 모델 생성0건·새 사람 검수0건**이다.

모델 지침에는 **근거 순서는 현재값·기준값이며 문장은 기준 기간 대비 현재 기간으로 쓸 것**, 내부 코드 대신 한국어로 설명할 것을 명시했다. 이번 지침으로 새 생성하지 않았으므로 생성 효과는 미평가다. 구조 코드·근거 ID·수치·판정·진단과 도구 실행 이력의 구분은 유지한다. 모델 원문을 치환하거나 수정해 통과시키지 않는다.

## 방향 검사 범위

검사는 qoq/yoy 계산값이 있는 결과의 **명시적 연도·분기 쌍**에 적용한다.

- `2024년 3분기 대비 2025년 3분기`, `X에 비해 Y`, `X보다 Y`, `from X to Y`는 기준→현재 순서다.
- `X compared with/to Y`는 현재→기준 순서다. `2024 Q3`, `Q3 2024`, `2024년 3분기` 형태를 지원한다.
- 연도만 또는 분기만 명시하면 두 근거 중 하나로 유일하게 특정되어야 한다. 같은 연도·같은 분기의 모호한 표기는 추측하지 않는다.
- 발견한 날짜 비교가 지원 문법에 맞지 않으면 보류한다. 연도 뒤의 상반기·9개월·Q9 같은 미지원 기간 한정어를 버리고 연도만 읽지 않는다.
- 명시된 기간 쌍이 없는 문장, 모든 자연어 표현·인용·부정의 의미를 보장하지 않는다. 검사 통과는 문장 전체 의미 인증이 아니다. 후속 지원이 필요한 문법과 단순 미언급은 구분해야 한다.

## 추가 합성 문장14건

실행 전·제품 수정 전에 [문장·예상 통과/거부](../data/prose-v8-fix-20261111/synthetic-cases.json)를 작성했다. 테스트 파일의 문장과 별도이며, 삼성·현대의 알려진 v8 도구 결과를 사용했다. 예상 판정은 기간의 현재/기준 관계와 문장 조건으로 AI가 작성했고 새 사람 검수는 없다. AI가 설계한 문장이므로 독립·맹검 평가셋이라고 부르지 않는다.

첫 실행 예상 판정 일치는 **기존 규칙7/14 → 새 규칙14/14**다. 정방향, 역방향, 모호한 분기, 미지원 반기, 부정문·모순, 내부 코드와 한국어 표현을 포함한다. 결과를 본 뒤 문장·정답·제품 코드를 조정하지 않았다. 새 LLM 생성·검색 질의 평가·원문 PDF 파싱은 아니다.

로컬 검사 지연 중앙값: 실제 응답 재생0.2345ms, 합성 문장0.057ms. 재생 최대2.572ms. 단일 순차 실행이며 네트워크·모델 지연·고객 환경 성능이 아니다.
