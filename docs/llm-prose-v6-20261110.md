## 원문 PDF와 평가 정답

- 캐시된 [삼성2022 Q3 PDF](https://images.samsung.com/is/content/samsung/assets/global/ir/docs/2022_3Q_Interim_Report_vF.pdf#page=37)와 [현대2025 Q3 PDF](https://www.hyundai.com/content/dam/hyundai/ww/en/images/company/investor-relations/financial-Information/report-en/2025/2025-q3-consolidated-audit-report-en.pdf#page=8)의 SHA256·페이지 수를 확인하고 현재 파서로 다시 추출했다. 이번에 새로 다운로드한 문서는 아니다.
- 삼성37쪽32셀 추출 중 KRW16개, 현대8쪽16셀을 기존 동결 정답과 대조해 모두 일치했다. **정답 수치를 파서에 주입하지 않았다.** 이32개는 새 사람이 검수한32개가 아니다.
- 새 도구 결과는 파싱한 사실을 격리된 평가용 출처 목록에 등록하고 실제 `compare()`로 만들었다. 상태·이슈는 과제별로 정했고, 비율은 원문 대조된 금액으로 `(현재−기준)×100/기준`을 별도 검산했다. 이 과제 작성·검산은 같은 작업의 AI가 했으며 새 사람 정답 검수는 없다.
- 모델 실호출 시에는 이 준비 결과를 재생한다. 새8건은 MCP 통신을 실행한 결과가 아니며 공개 제품의 정본이나 기업 목록도 바꾸지 않았다. 기존8건과 합쳐서 ‘PDF부터 MCP·LLM까지 새로16건 실행’으로 쓰지 않는다.
- [입력·파싱 대조 기록](../data/llm-prose-v6-20261110/new-inputs.json), [동결 파일](../data/llm-prose-v6-20261110/freeze.json).

## 승인 요청 계약

|항목|범위|
|---|---|
|모델|`gpt-5.4-mini-2026-03-17`, reasoning none — 앞선 평가와 동일|
|대상·횟수|기존8건+새8건, 최대16회, 각1회, 자동 재시도0회|
|입력|회당 사전 제한8,500; 현재16요청의 최대 계산값7,511|
|출력|회당 `max_output_tokens=700`|
|요청 제한|60초, 실패 시 즉시 중단·재시도 금지|
|단가|입력100만 토큰당$0.75, 출력$4.50. 2026-11-10 [공식 문서](https://developers.openai.com/api/docs/models/gpt-5.4-mini) 확인|
|최대 추정|`16 × (8500 × 0.75 + 700 × 4.50) / 1,000,000 = $0.1524`|
|승인 예산|$0.16, 세금·환율 제외|
|키|기존 GitHub Actions `OPENAI_API_KEY` 재사용. 값 조회·출력 없음|
|청구액|미조회. 실행 후 usage 기반 추정과 구분|

입력 사전 제한은 전체 직렬화 요청의 UTF-8 바이트 수+프레이밍 여유1024로 계산한다. API가 보장하는 입력 토큰 하드 상한은 아니며 usage가 초과하면 추가 호출을 중단한다. 출력700은 API 파라미터다. 무응답 등 사용량 미확인 실패는 비용 추정에서 별도로 표시한다. 도구 호출 기능·웹 검색·이미지 입력은 사용하지 않는다.

최종 동결 content SHA256: `ea408743594cf4fe9f640f3d423ee0a564e365a1e9ffbbeada947ccab900f054`.

수동 워크플로 기본 승인은false이며, 기존 실행·재실행·동결 불일치는 키가 제공되기 전에 차단한다. 로컬 실행은 별도 명시적 승인 플래그와 새 출력 디렉터리가 필요하다. 플래그는 실제 사용자 승인을 대신하지 않는다. 이전 준비 도중 workflow의 setup-python 버전이 일괄 치환된 것을 원래v5로 바로잡았고, 그 이전 동결본도 보존했다. 위 최종 해시만 실행 대상으로 사용한다.

## 결과와 사람 검수 준비

- 기존8건은 전후 원응답을 함께 보존한다. 새8건에는 비교할 이전 응답이 없으므로 별도 집계한다.
- 생성 성공, 구조 필드 일치, 현재 제품 방어 통과, 기존 자동 감사 경고, 비용·지연시간을 따로 기록한다. 제품이 보류한 모델 원문도 평가 파일에는 남긴다.
- 과거 b 판정을 새 응답에 복사하지 않는다. `human-review.json`의 검수자·시각·판정은 모두 빈칸으로 생성한다. [b에게 전달할 검수 안내](validation-kit/llm-prose-v6-review-20261110.md).
- LLM-as-judge 호출 없음. `%`·문서 지칭 등의 규칙 통과만으로 문장 전체를 참으로 판정하지 않는다. 모델 한 번씩의 생성과 작은 표본이며 일반 정확도·인과적 프롬프트 효과를 보장하지 않는다.
- 공개 제품 모델은 GPT-4.1 mini이므로 이 GPT-5.4 mini 평가를 제품 모델 실측 성능으로 표현하지 않는다. 평가용 격리 실행이며 공개 API의 캐시·요금 흐름은 별도 회귀 대상으로 남는다.
