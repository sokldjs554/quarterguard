# 사람이 직접 작성하는 새 평가 사례

## 무엇이 달라지는가

- AI 작성 문장을 새 사람이 읽음: AI 합성 사례 + 새 사람 검수.
- 사람이 공개 원문에서 질문과 정답/근거를 직접 작성: 사람 작성 사례.
- 기존 사례/정답/수정에 쓰지 않은 자료와 질문을 실행 전 고정: 별도 평가 후보. 결과를 보고 수정에 사용한 뒤에는 그 사례를 새로운 독립 평가라고 계속 부르지 않는다.

기존 b도 작성 가능하나 기존 자료에 익숙하므로 그 사실을 기록한다. 새 참여자가 독립적으로 작성하면 작성자 독립성은 추가되지만, 문서/질문 중복 여부도 확인해야 한다. 같은 사람의 여러 회차는 인원1명이다.

## 전달 메시지

> 공개 기업공시 PDF를 읽고 실제로 물어보고 싶은 질문4~6개를 직접 적어 주세요. 먼저 기존 앱 답변·평가 문장·정답은 보지 말아 주세요. 각 질문에 답변 가능한지, 조건 추가가 필요한지 판단하고 금액과 기간·연결/별도·통화·단위·원문 쪽/표/행/열을 별도 정답지에 적어 주세요. 원문이 모호하면 추측하지 말고 미확인으로 남겨 주세요. 질문과 정답을 먼저 저장한 뒤 앱을 사용합니다. 회사 비공개 자료는 쓰지 않습니다.

실행 전 질문/정답과 사후 앱 결과를 별도 파일에 보관한다. 앱 답변을 보고 정답을 수정하면 원래 정답을 남기고 변경 이유를 적는다. 다른 회사/기간·미지원 사례를 포함할 수 있으며 실패도 결과다. 일반 참여자가 어려운 금융 판단을 하면 미확인으로 두고 금융 경험자의 검토 여부를 별도 기록한다.

새 일반인이 사용하면 ‘일반 사용자 사용성 검증’이다. 신규 참여나 관련 회사 재직만으로 금융기관 고객 환경 배포·도입이 되지 않는다. 실제 업무 사용/조직 접근·자료 사용·배포 허가가 확인돼야 해당 범위로 기록한다. 이 양식은 실제 참여 기록이 아니다.
