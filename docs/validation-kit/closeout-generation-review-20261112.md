# 마지막 새 응답 검수 안내 — 생성 전 준비

이번에는 기존20개 과제에 대해 **새로 생성한 응답**을 검수한다. 이전 응답의 판정은 새 기록에 복사하지 않는다. 현재는 승인 전이므로 새 응답·실제 검토 시각·판정은 비워 둔다.

생성이 끝나면 `human-review.json`의 새 원응답과 동일 도구 결과를 제공한다. 자동 검사에서 거부한 응답도 포함한다. 사례별 공식 원문 URL·문서·PDF 페이지는 각 `tool_result.evidence`에서 확인할 수 있다. 본인은 주로 금액·기간·연결 범위·단위·비교 방향·문서 귀속과 보류 이유를 대조하면 된다.

|---|---|---|---|---|---|
|생성 후 실제 case_id 사용||||||

- 검토 날짜·시간대와 실제 환경은 수행한 값만 적는다.
- 원문 이미지·추출 텍스트 중 무엇을 읽었는지 적고, 제공된 자료·받은 도움을 기록한다.
- `status`, `value`, `issues`, `evidence_ids`는 도구 결과와 별도로 대조한다. 문장이 맞아도 구조가 틀릴 수 있다.
- 도구는 기간 불일치를 보고했을 뿐인데, 실행하지 않은 세부 조건을 실행 이력처럼 주장하지 않는지 확인한다.
- 근거 없음은 해당 검색 범위의 결과로 한정해야 한다. 회사 전체 실적 부재나 전체 수집 범위 부재로 확대하지 않는다.
- 구조 일치나 자동 통과를 보고 문장 판정을 그대로 정하지 않는다. 자동 결과를 참고했다면 그 사실도 기록한다.

검수 결과가 오면 개별 행으로 집계한다. 전체 집계와 행별 판정이 다르면 원제출을 보존하고 차이를 명시한다. 같은 b의 후속 검수이므로 새 참여자로 세지 않는다.
