# 실제 사용자 검증 준비 키트

**후속 기록:** [세션 b](session-b-20261108.md)에 금융회사 기업 재무분석·여신심사 지원 경력 3년인 친구의 문서·코드 검토 의견과 최종 공개 동의를 기록했습니다. 역할·경력·시각은 진행자 제공 정보이며, 이 초기 의견은 [후속 모바일 직접 수행](session-b-task-followup-20261108.md) 및 금융 수치 정확성 인증과 구분합니다.

**2026-11-08 상태:** [개발자 시연 + 대학생 1명의 실제 피드백](session-a-20261107.md)을 기록했습니다. 모든 화면 조작·수치 대조는 작성자가 수행했고 대학생은 의견을 제공했습니다. 금융 수치의 독립 전문 검수·고객사 배포는 미실시입니다. 아래 진행 안내와 빈 양식은 다음 참여를 위한 준비 자료이며 가상의 결과를 채우지 않습니다.

목적은 공개 재무자료를 검토하는 사람이 **출처 확인 → 비교 조건 확인 → 금액 대조 → 판단 보류** 흐름을 이해하고 수행하는지 관찰하는 것이다. 참가자는 실제 역할대로 기록한다. 친구나 일반 사용자에게 부탁했다면 `친구 / 일반 사용자`로 쓰고, 금융 전문가·고객으로 바꾸지 않는다. 같은 프로젝트의 작성자 본인 검토와 제3자 사용자 검증도 분리한다.

진행자는 다음 순서로 약 20~30분 세션을 준비한다. 시간은 계획이며 측정 결과가 아니다.

1. [동의 안내](consent.md)를 먼저 전달하고 참여 동의를 기록한다. 공개 인용·스크린샷 동의는 참여 동의와 별도다.
2. [빈 기록지](session-template.md)를 로컬의 비공개 위치에 복사한다. 역할·경력·개발자와의 관계·환경을 확인하되 이름·연락처·소속 회사명은 수집하지 않는다.
3. [업무 카드](tasks.md)를 하나씩 보여준다. 먼저 정답을 가르치지 말고, 도움을 준 시점과 내용을 기록한다.
4. 결과와 막힘을 원문에 가깝게 기록한다. 원문을 바꾼 요약은 요약이라고 표시하고, 긍정 평가·완료율을 추측하지 않는다.
5. 공개하려는 **구체적인 발췌본**을 참가자가 확인한 뒤 동의 범위에 한해 반영한다. 원기록은 기본 비공개이며 이 저장소에 넣지 않는다.

기본 화면은 [공개 데모](https://quarterguard.onrender.com) 또는 로컬 앱이다. 버전·접속 일시를 기록하고, 연결 실패·절전 대기를 업무 실패와 분리한다. 이 키트의 업무 데이터는 [2024년 정본](../../data/facts.json)과 [공식 보고서 목록](../../data/sources.json)에 한정한다. 새 연도 파서 평가를 화면 지원으로 추정하지 않는다. 외부 API나 유료 LLM 버튼은 이 세션에 필요하지 않다.

실제 고객 환경에서 진행하려면 [고객 환경 체크리스트](customer-access-checklist.md)를 먼저 작성한다. 현재 고객명, 승인, 고객 데이터, 접근권한, 배포 환경은 모두 미확보다. 공개 데이터 일반 사용자 세션만 끝났다면 그 사실만 기술한다.

사용자가 다음으로 할 일은 동의한 참가자 한 명과 위 업무를 수행하고 기록지를 채우는 것이다. 그 전까지 사용 가능한 표현은 **“공개 데이터 기반 사용자 검증 시나리오·동의·기록 양식을 준비했다”**이다. “사용자가 오류를 발견했다”, “고객 피드백으로 수정했다”, “전문가 검증을 마쳤다”는 실제 확인과 근거 없이는 쓰지 않는다.

## 현재 참여 가능성

금융 분야 친구 b의 직무·경력·동의와 문서·코드 검토 의견은 [후속 기록](session-b-20261108.md)에 정리했습니다. 후속 [모바일 직접 수행 보고](session-b-task-followup-20261108.md)도 확보했습니다. 금액 아래 조건 표시를 반영한 뒤 [b의 직접 재확인 보고](session-b-mobile-recheck-received-20261109.md)도 받았습니다. 정성 의견과 세 과제 수행 보고이며 시간 단축이나 금융기관 고객 검증을 뜻하지 않습니다. [초대 문안·업무 카드·빈 기록지](finance-peer-review.md)를 사용하고, [과거 모집 상태](recruitment-status.md)는 당시 기록으로 보존합니다.

**추가 후속:** [표 위 설정 이동 버튼에 대한 b의 직접 확인 의견](session-b-recovery-feedback-received-20261109.md)을 접수했다. 그 뒤 추가한 [설정 닫고 결과 보기](../settings-return-20261109.md) 기능에 대해 같은 참여자가 [이번 복구 흐름에서 막힌 부분이 없었다는 후속 의견](session-b-settings-return-received-20261109.md)을 전달했다. 사람의 정성 보고와 자동 검사 결과를 구분한다.

**원문 정답 검수 준비:** [셀8개·질의4개 안내](source-gold-review-20261109.md)와 [빈 기록지](source-gold-review-sheet-20261109.md). 기존 앱 사용성 확인과 다른 과제다. 이후 [b의 직접 검수 보고](session-b-source-gold-20261109.md)를 받아 셀8/8·질의4/4 일치를 기록했다. 삼성4개는 추출 텍스트 기준이며 이미지 확인은 남았다.
