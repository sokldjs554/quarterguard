## 자동검사와 사람 판정의 차이

- b의 전체 판정: **참5, 모호3, 거짓0, 판단 불가0**. ‘모호’를 통과나 금융 수치 오류로 바꾸지 않는다. 일반 정확도 62.5% 또는 오류율 37.5%로 제시하지 않는다.
- 자동 경고7건 중 사람 판정은 참5·모호2였다. 자동으로 위반이 감지되지 않은 `no-evidence`도 사람은 모호로 판단했다. 규칙 경고와 의미 판정의 범위가 다르므로 경고7건을 실제 오류7건으로 쓰지 않는다.
- `normal-qoq`의 ‘참’에도 통화/단위 주석이 있다. 이를 삭제하거나 ‘완벽한 설명’으로 확대하지 않는다. 구조화 인용 ID 일치와 본문의 문서·페이지 가독성도 다른 검증 항목이다.
- 사례별 전체 판정과 이유를 받았다. 빈 양식의 모든 세부 칸을 사람이 작성했다고 추정해 채우지 않는다. 지정 응답8개의 단일 검수자 보고이며 모델의 일반 정확성 인증이 아니다.

후속 개선 후보는 표시 단위를 ‘백만 원’으로 명시하고 내부 배율과 구분하기, 근거 부재를 검색 범위로 한정하기, 본문에 문서·페이지를 제시하기다. **이번 반영은 기록 정리이며 프롬프트·검사기·제품 동작을 수정하거나 수정 후 재평가한 것은 아니다.**
