# 실제 고객 환경 검증 전 체크리스트

**현재 상태: NOT_PERFORMED / 실제 고객 승인·데이터·환경·접근권한: 미확보.** 공개 데모와 일반 사용자 세션은 실제 고객 환경 검증을 대체하지 않는다. 이 체크리스트는 어떤 권한도 부여하지 않는다.

| 확인할 내용 | 승인 주체·범위·근거·일시 또는 미확보 사유 |
| --- | --- |
| 실제 고객 관계 및 고객 측 책임자 확인(공개본에는 이름/회사 식별정보 제외) | NOT_PERFORMED |
| 검증 목적·대상 업무·성공/중단 기준 | NOT_PERFORMED |
| 고객 조직의 테스트 허가, 허가자 권한, 허가 기간 | NOT_PERFORMED |
| 데이터 소유자 사용 허가 및 공개/비공개 분류 | NOT_PERFORMED |
| 사용할 데이터의 기업·기간·문서 종류·정정 여부 | NOT_PERFORMED |
| 개인정보·비공개 회사자료 제거/대체 확인 | NOT_PERFORMED |
| 데이터 반출·외부 서비스 전송·보관·삭제 조건 | NOT_PERFORMED |
| 테스트 환경 URL·배포 버전·환경 소유자 | NOT_PERFORMED |
| 로컬/고객 테스트 환경/운영 환경 구분과 허용 작업 | NOT_PERFORMED |
| 필요한 읽기 권한·기간·계정 발급·회수 절차 | NOT_PERFORMED |
| 네트워크·문서 접근·API 키 관리 주체(키 값 기록 금지) | NOT_PERFORMED |
| 외부 API 호출 필요 여부·별도 비용 승인·한도 | NOT_PERFORMED |
| 허용 입력·기능·사용자 수·실행 시간·로그 범위 | NOT_PERFORMED |
| 장애 발생 시 중단·연락·복구 담당 및 절차 | NOT_PERFORMED |
| 결과 원기록의 비공개 보관 위치·접근자·삭제일 | NOT_PERFORMED |
| 공개 가능한 결과·고객 명칭/인용/화면의 별도 승인 | NOT_PERFORMED |

첫 세션은 공개자료만 사용한다. 비공개 데이터가 필요한 별도 고객 검증은 구체적인 허가와 취급 범위를 정한 뒤 진행해야 하며, 이 준비 키트나 일반 참가자의 동의로 허용됐다고 보지 않는다. 승인·접근이 없는 경우 결과는 `BLOCKED: customer authorization/access not secured`로 기록하고 고객 검증 수행 횟수는 0으로 유지한다.
