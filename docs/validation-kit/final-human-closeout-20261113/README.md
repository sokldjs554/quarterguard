# N01–N20 실제 검수 수신

사용자가 전달한 기존 참여자 b의 후속 표를 [제출 내용](submission.md)과 [구조화 기록](review.json)에 보존했다. 강조 표시와 표 형식만 정리했으며 AI가 사람 판정·이유를 작성하지 않았다. 같은 b이므로 새 참여자로 세지 않는다.

전달일: **2026-11-13 KST**. 실제 검토 날짜·시각, 이번 환경과 받은 도움은 제출되지 않았다. 이전 세션의 정보를 복사해 채우지 않았다. 기존의 수행자·공개 확인 맥락을 유지한다.

|평가 대상|결과|
|---|---|
|설명20건|참17 · 모호3 · 거짓0|
|구조 필드|20/20 일치|
|근거 ID|20/20 일치, 빈 목록2건 포함|
|본문 출처|18건 일치, 근거 없는2건은 해당 없음|

모호한 사례는 N01(설명에 증가율 누락), N04(누적 차감과 직접 공시 금액의 일치 결론 누락), N16(다른 연도의 같은 분기를 동일 기간처럼 읽을 수 있는 표현)이다. 숫자·구조가 맞는 것과 질문에 충분히 답하는 것은 다르다.

생성 당시 자동 통과8건 중 사람 참7·모호1(N04)이었고, 자동 보류12건 중 참10·모호2였다. N04에 대한 마지막 결론 검사를 추가한 후 **기존 원응답 재검사7/20 통과**, 참10·모호3건 보류다. 새 생성이나 새 사람 검수가 아니며 원응답과 위 판정은 바꾸지 않았다.
