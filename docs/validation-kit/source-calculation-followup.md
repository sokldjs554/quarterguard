# 연간·잔액·비중 계산 직접 확인 — 미수행 양식

이 문서는 수행 방법과 빈 기록 양식이다. 실제 수행·검토 의견을 미리 작성하지 않는다. 기존 참여자의 여러 후속 확인을 새 참여자 수로 세지 않는다.

공개 데모 → 근거 검색 → SK하이닉스 → 선택 근거로 계산. 공개 자료만 사용한다.

- 현금 A2024말/B2023말을 원문 PDF191/인쇄F-73과 대조하고, 차이3,617,788백만 원·47.6820%인지 확인한다.
- 연간 매출의 증가와 연말 재고의 감소를 각각 확인하고, 흐름과 잔액을 같은 개념으로 읽지 않았는지 설명한다.
- 2024DRAM과 같은 표의 합계(PDF264/인쇄F-146)로67.5777%를 확인한다. B를2023합계 또는 손익계산서 매출로 바꿔 보류를 확인한다.
- 영업손익의 원문 PDF193/인쇄F-75를 읽고, 금액 차이31,197,632백만 원은 나오지만 증감률은 보류되는 이유를 설명한다.
- 재고 개월분에서 추가로 정해야 하는 분모·기간·재고 정의를 기록한다.
- 조건 변경 후 이전 결과/저장이 사라지는지 확인하고 새 JSON에서 문서·쪽수·행·열·계산 방향을 다시 찾는다.
