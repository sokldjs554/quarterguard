# b에게 전달할 v6 검수 안내 — 아직 수행하지 않은 양식

현재 새 LLM 응답은 없다. 승인 후 생성된 원응답·도구 결과·원문 링크를 함께 제공한다. 같은 참여자 b의 후속이면 새 참여자로 세지 않는다. 검수 결과·소요시간·도움·동의를 AI가 대신 작성하지 않는다.

전달 문안:

> 이전에 지적해 준 표현 문제를 반영한 뒤 생성한 설명을 확인해 줄 수 있을까? 기존 과제8건의 전후 비교와 삼성2022·현대2025의 새 과제8건을 구분해 뒀어. 자동 검사가 통과했는지와 관계없이, 각 설명을 원문·도구 결과와 대조해 참/거짓/모호/판단 보류로 적어 줘. 시간이 부족하면 확인한 사례만 남겨도 돼. 새 과제의 수치·기간·행·열 정답에도 틀린 부분이 있으면 지적해 줘.

확인할 항목:

1. 금액·연도·단독/누적·연결/별도·통화·단위가 실제 근거와 같은가? 감소율의 부호와 `%`가 맞는가?
2. 근거가 있는데 비교를 보류하는 경우, 근거를 못 찾았다는 설명을 덧붙이지 않았는가?
3. 문서·페이지·행·열과 근거ID가 각각 맞는가? 여러 문서를 ‘같은 보고서’로 잘못 지칭하지 않았는가?
4. 비교 보류 이유가 도구의 문제 목록과 같은가? 서로 다른 분기 자체를 잘못된 이유로 추가하지 않았는가?
5. 영어 내부 표현, 모호한 대명사, 빠진 단위 등 독자가 오해할 표현이 남았는가?

검수 날짜·시각/시간대, 사용 기기·OS·브라우저, 받은 도움, 실제 수행자, 이번 기록의 익명 GitHub·지원서 활용 확인 여부를 함께 적는다. 기존 동의를 새 결과의 공개 확인으로 대체하지 않는다. 공개할 문안을 검수자에게 다시 보여 주고 확인한 범위만 게시한다.

이번 금액/설명 검수는 금융회사 공식 승인·회사 환경 사용·독립 다수 전문가 평가가 아니다. ‘참’도 해당 문장과 지정 근거 범위의 판정이며 전체 모델 정확성 인증이 아니다.
