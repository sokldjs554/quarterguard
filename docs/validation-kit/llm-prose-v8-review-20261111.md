# v8 실제 응답 검수 방법

[새 실제 응답16건](llm-prose-v8-actual-20261111.md)을 먼저 읽고 각 문장을 원문·도구 결과와 대조한다. 같은 b의 후속 검수이며 새 참여자로 계산하지 않는다. 이미 확인한 역할·공개 동의는 다시 묻지 않는다. 이 문서와 빈칸은 검수 완료 기록이 아니다.

1. **설명 문장:** 금액, 현재/기준 기간의 방향, 단독/누적, 연결/별도, 통화·표시 단위, 증가율의 부호·% 및 보류 이유가 맞는지 판정한다. 참·모호·거짓·미확인 중 실제 확인한 결과를 적는다.
2. **구조 필드:** `status`, `value`, `issues`를 도구 결과와 대조한다. 문장에 %가 있어도 구조 값에는 도구에 없는 %를 붙이면 안 된다.
3. **근거 ID·출처:** ID 철자·순서와 문서·쪽·행·열을 확인한다. 본문이 “같은 보고서”라고 말할 때 실제로 같은 자료인지도 본다.
4. **도구와 진단:** 별도 재계산에서 확인한 조건을 도구가 실제 실행한 조건이라고 단정했는지 본다.

먼저 새 응답을 판정하고, 접힌 이전 응답은 그다음에 비교한다. 자동 통과/거부를 사람 판정으로 옮기지 않는다. 일부만 검수했으면 나머지는 미검수로 남긴다. 마지막에 실제 수행 날짜·환경·받은 도움을 기록한다. 이번 전달만으로 실제 검수가 이뤄졌다고 기록하지 않는다.
