# 일반 사용자 참여 안내와 빈 기록지

처음 만난 일반인에게 직접 사용을 부탁했다면 실제 일반 사용자 사용성 테스트다. 그것만으로 금융 업무 고객, 금융기관 고객 또는 고객사 환경 배포가 되지는 않는다. 서비스가 필요한 당사자가 실제 목적을 위해 사용했다면 그 목적과 사용 맥락을 구체적으로 기록한다. 무료 사용자도 고객일 수 있지만, 지원서에서는 구체적인 역할·사용 사실을 먼저 적는다.

## 전달할 안내

“공개 공시 숫자를 확인하고 비교하는 개인 프로젝트입니다. 약 10분 동안 직접 사용해 보고, 막히거나 헷갈리는 부분을 알려 주세요. 금융 지식이나 정답을 평가하려는 테스트는 아닙니다. 참여는 자율이며 중단할 수 있습니다. 회사 비공개 자료와 개인정보는 입력하지 않아도 됩니다.”

참여·메모 보관·캡처·익명 지원서 활용·GitHub 공개는 각각 의사를 확인한다. 실제 공개할 요약을 보여 주고 공개 범위를 확인한다. 원본 보관 기간과 삭제 연락 방법도 정한다. 이 양식은 참여 결과가 아니며 빈칸을 AI가 실제 기록처럼 채우지 않는다.

## 직접 수행할 과제

1. 데모에서 A/B 매출 아래의 기간·연결 범위·단위를 읽고 두 수치의 차이를 설명한다.
2. 원문 링크에서 지정된 페이지의 행·열을 찾아 숫자와 단위를 확인한다.
3. B를 누적으로 바꾸고, 성장률을 보고서에 사용해도 되는지 판단한다. 안내로 기간을 복구한다.
4. B를 별도로 바꾸고 판정 이유를 설명한 뒤 연결로 복구한다.
5. 실제 CSV를 내려받아 금액·기간·출처를 다시 찾는다.

금융 용어를 모르면 그대로 기록하고 설명을 제공한 시점도 남긴다. 진행자가 대신 조작한 부분은 직접 수행으로 세지 않는다.

|기록 항목|실제 확인 내용|
|---|---|
|익명 ID / 작성자와 관계|미기입|
|직무·금융 관련 경험|미기입 — 없으면 없음|
|평소 사용 목적 / 실제 업무에 사용했는지|미기입|
|날짜·시각 / 기기·브라우저 / 화면 버전|미기입|
|동의 범위 / 보관 기한 / 삭제 연락 방법|미기입|
|과제별 직접 조작·읽은 값·판단|미기입|
|실패·막힌 부분 / 진행자 도움|미기입|
|개선 의견 / 공개 요약 확인|미기입|

완료 후 표현 예: “일반 사용자 1명이 공개 데모에서 기간 불일치 확인과 복구 과제를 직접 수행했다.” 실제 수행 결과에 맞게 작성하고, 같은 사람의 재참여는 고유 참여자 수에 더하지 않는다. 현재 고유 외부 참여자 2명은 새 참여가 확인되기 전까지 그대로 유지한다.
