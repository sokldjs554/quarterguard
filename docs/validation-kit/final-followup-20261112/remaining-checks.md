# 남은 저장·상태 확인 두 과제

이미 제출한 정상 계산·보류·복구를 전부 반복할 필요는 없다. 아래에서 직접 확인한 결과만 적는다. 실패·미확인도 유효한 기록이다. 공개 자료만 사용한다.

## A7: Apple 보류 결과 저장과 질문 변경

1. [데모](https://quarterguard.onrender.com/)에서 Apple 문서를 선택하고 “2024년 중국권 매출 감소는 판매량 감소만으로 설명할 수 있나?”를 실행한다.
2. JSON 저장 후 다운로드 완료 여부와 파일명을 확인하고 파일을 텍스트 편집기로 연다. 질문, Apple 문서, 인쇄 22쪽 근거, 판매량만으로 확정할 수 없다는 보류 이유가 해당 결과와 맞는지 읽는다. 키 이름이 예상과 달라도 실제 내용을 기록한다.
3. 질문을 다른 질문으로 바꾸되 실행 전 상태를 먼저 본다. 이전 결과가 새 질문의 결과처럼 표시되거나 저장되는지 확인한다. 이후 새 질문을 실행해 새 결과와 질문이 맞는지 확인한다.
4. 파일 열기·상태 확인이 어려우면 어디까지 했는지만 남긴다.

## S4: 재고 개월분 보류 결과 저장

1. SK하이닉스 재고 개월분 확인 과제를 실행해 정의 확인이 필요하다는 보류 결과를 만든다.
2. JSON 저장 후 다운로드 완료·파일명을 확인하고 파일을 연다.
3. 선택한 입력, 문서·원문 위치, 기말/평균 재고·분모·대상 기간을 먼저 정해야 한다는 보류 이유가 화면과 맞는지 읽는다. 수치 계산을 수행하지 않은 상태가 저장 결과에서도 분명한지 확인한다.
