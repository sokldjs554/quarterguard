# b에게 부탁할 설명 개선 후 재확인

**검수 안내와 빈 양식입니다. 아직 수행·판정 기록이 아닙니다.** 실제 새 응답을 확보한 뒤 전달하며 기존 응답을 개선 후 출력으로 제시하지 않습니다. 진행자가 b에게 직접 전달하고 결과를 받아야 합니다.

## 전달 문구

> 지난번 지적해 준 단위·검색 범위·출처 표현을 반영한 설명을 다시 확인 부탁해. 먼저 새 문장을 도구 결과와 공식 PDF에 대조해 참/거짓/모호/판단 불가와 이유를 적어 줘. 금액이 맞아도 설명이 모호하면 그대로 남겨 줘. 이전 응답과 비교할 때는 무엇이 좋아졌고 무엇이 남았는지도 적어 줘. 아래 작업을 실제로 수행한 날짜·환경·받은 도움과 이번 익명 요약의 공개 가능 범위도 함께 알려 줘. 회사의 비공개 자료는 필요 없어.

## 확인할 자료와 기준

- 공식 삼성전자 [2024년3분기 PDF p.34](https://images.samsung.com/is/content/samsung/assets/global/ir/docs/2024_3Q_Interim_Report.pdf#page=34), [반기 p.48](https://images.samsung.com/is/content/samsung/assets/global/ir/docs/2024_Half_Interim_Report.pdf#page=48), [반기 p.104](https://images.samsung.com/is/content/samsung/assets/global/ir/docs/2024_Half_Interim_Report.pdf#page=104).
- 새 모델 응답의 **문장 자체**를 확인한다. 별도 도구 안내가 정확하다는 이유로 모델 문장의 누락을 통과시키지 않는다.
- KRW(통화)와 백만 원(표시 단위)을 구분하는가? 내부 `scale`을 원문 표 머리글로 잘못 표현하지 않는가?
- 근거가 없을 때 ‘해당 검색 범위에서 확인할 수 없음’으로 한정하는가? 실제 실적·보고서가 존재하지 않는다는 주장으로 읽히지 않는가?
- 본문의 문서명·페이지가 실제 원문의 표·행·열에 연결되는가? 숫자·연도·3개월/누적·연결/별도가 맞는가?
- 비교 보류가 유지되는가? 사례 이름에 ‘충돌’이 있어도 실제 응답에 오류가 없으면 이름만으로 오류 판정하지 않는다.
- 자동 표시 결과는 참고용이다. 같은 사람이 이미 본 개발 사례이며 독립 블라인드 실험으로 기록하지 않는다.
