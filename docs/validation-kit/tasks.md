# 공개자료 업무 카드와 진행자 관찰 기준

실행 상태는 모두 **NOT_PERFORMED**다. 아래 예상값은 정본 기반 진행자 기준이며 참가자의 답변이 아니다. 참가자에게는 각 업무의 요청 문장만 먼저 보여준다. 모든 페이지 번호는 PDF의 1부터 시작하는 페이지다.

## T1 — 출처에서 비교 조건 찾기

**참가자 요청:** “삼성전자 2024년 3분기 연결 매출액의 근거를 찾아 주세요. 어느 보고서의 어느 행·열인지, 기간과 통화·단위를 설명해 주세요.”

진행자 기준: 3Q 보고서 p34, Revenue, `2024 Q KRW`, 2024-07-01~09-30, 연결(CFS), 백만 원, 79,098,731. 정본 ID: `s24q3-CFS-revenue-2024-q-KRW`. [공식 PDF](https://images.samsung.com/is/content/samsung/assets/global/ir/docs/2024_3Q_Interim_Report.pdf). 앱의 재구성 근거표와 발행사 원문이 서로 다른 표시라는 점도 확인한다. 원문 접근이 막히면 막힘으로 기록한다. 원문을 열지 못한 상태에서 원문 확인 완료로 쓰지 않는다.

관찰: 근거 진입 경로, 문서·페이지·행·열 찾기, 3개월/9개월 혼동, 금액과 배율 구분, 도움 여부.

## T2 — 조건을 맞추고 금액 대조하기

**참가자 요청:** “같은 회사의 2024년 2분기 연결 매출과 3분기를 비교해 주세요. 비교가 가능한 이유와 증감률의 근거를 설명해 주세요.”

진행자 기준: A는 위 Q3, B는 `s24q2-CFS-revenue-2024-q-KRW`, 반기 보고서 p48의 Revenue `2024 Q KRW`, 2024-04-01~06-30, 74,068,302백만 원. [공식 PDF](https://images.samsung.com/is/content/samsung/assets/global/ir/docs/2024_Half_Interim_Report.pdf). 같은 기업·항목·연결 범위·통화, 인접한 3개월 조건이다. `(79,098,731 / 74,068,302 - 1) × 100 = 6.7916%`. 숫자 클릭으로 근거를 확인하고 `비교 검증` 결과와 표 계산을 구분하도록 관찰한다.

추가 대조(시간이 허용되면): 같은 연결/KRW의 9개월 누적 225,082,634 − 반기 누적 145,983,903 = 79,098,731. 분기 직접 공시액과 일치한다. 별도 업무를 했는지 기록하고 하지 않았으면 NOT_PERFORMED로 남긴다.

## T3 — 누적/분기 혼합에서 판단 보류하기

**참가자 요청:** “B를 2024년 상반기 누적으로 바꿔 보세요. 현재 숫자로 전분기 대비 성장률을 보고서에 써도 될까요? 필요한 다음 행동을 설명해 주세요.”

진행자 기준: B `s24q2-CFS-revenue-2024-ytd-KRW`, 2024-01-01~06-30, 145,983,903백만 원. A 3개월과 B 6개월은 QoQ 조건에 맞지 않으므로 `needs_review`, `PERIOD_MISMATCH`, 성장률 없음. 참가자가 숫자를 억지로 계산하지 않고 조건 수정 또는 판단 보류를 선택하는지 본다. 단순한 “에러 발생”보다 어떤 조건이 맞지 않는지 설명하는지 기록한다.

## T4 — 연결/별도 혼합에서 판단 보류하기

**참가자 요청:** “기간은 다시 두 개의 단독 분기로 맞추고 B만 별도 보고서로 바꿔 보세요. 결과와 근거를 보고 비교 가능 여부를 판단해 주세요.”

진행자 기준: A `s24q3-CFS-revenue-2024-q-KRW`, B `s24q2-OFS-revenue-2024-q-KRW`, 반기 보고서 p104. `needs_review`, `SCOPE_MISMATCH`, 성장률 없음. A/B의 범위를 동일하게 확인하기 전까지 보류해야 한다. 개인 확인 체크나 메모가 자동 판정을 바꾸지 않는다는 점을 이해하는지도 관찰한다.

## 종료 질문 — 최대 세 가지

1. 출처·조건·계산·보류 중 가장 막힌 부분과 그 이유는 무엇이었나요?
2. 이 결과를 실제 보고서에 사용하기 전에 무엇을 더 확인해야 하나요?
3. 이 작업을 다시 한다면 어디를 바꾸면 도움이 될까요?

답변을 유도하지 말고 실제 발언과 진행자의 해석을 나누어 적는다. 이 세션만으로 사용 의향, 고객 수요, 제품 정확도나 금융 전문성을 입증하지 않는다.
