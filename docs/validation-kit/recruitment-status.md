# 참여 가능성 확인 · 아직 세션 미수행

사용자는 이 작업 중 “지인 일반 사용자도 있고, 회계쪽도 있어”라고 알렸다. 아래는 참여 가능성에 관한 사용자 진술이며 실제 세션·동의·전문가 검수 완료 기록이 아니다. 실명·연락처·회사명은 기록하지 않는다. 두 유형의 참여자가 서로 다른 사람인지, 실제 참여 인원도 확정하지 않았다.

|구분|현재 확인한 내용|남은 확인|수행 상태|
|---|---|---|---|
|일반 사용자 경로|지인 일반 사용자에게 참여 요청 가능하다는 사용자 진술|자발적 참여 동의, 실제 역할, 사용 환경, 공개 범위|NOT_PERFORMED|
|회계 관련 경로|회계 관련 분에게 참여 요청 가능하다는 사용자 진술|실무/전공/학습 등 실제 역할, 경험 기간 범위, 업무 분야, 이해상충·공개 동의|NOT_PERFORMED|

금융기관 고객이나 고객사 접근 권한은 확보됐다고 기록하지 않는다. 회계 관련이라는 표현만으로 현업 전문가·회계사 자격·검수 완료를 추정하지 않는다.

## 사용자에게 필요한 다음 행동

1. 아래 초대 문안을 전달하고 [동의 양식](consent.md)의 용도·공개 범위를 먼저 확인한다.
2. 참가자가 일반 사용자 경로인지, 어떤 회계 관련 경험을 갖는지 참가자 본인의 설명을 익명 코드로 기록한다.
3. [과제 카드](tasks.md)를 보여 주고 대신 조작하거나 정답을 먼저 설명하지 않는다. 막힌 지점과 도움을 준 내용을 기록한다.
4. [세션 기록](session-template.md)을 실제 관찰로 채운다. 의견을 저장소/지원서에 공개할 때는 동의 범위와 인용 문구를 다시 확인한다.

### 전달할 수 있는 초대 문안

“공개 금융 문서 검토 데모의 사용 흐름을 확인하고 싶습니다. 공개 보고서만 사용하며 개인·회사 비공개 자료는 필요 없습니다. 원문 확인, 비교 조건 선택, 숫자 대조와 보류 사유 확인을 약 20~30분 수행해 주실 수 있을까요? 참여는 자발적이고 중단할 수 있습니다. 이름·회사명은 공개하지 않으며, 결과를 지원서나 공개 저장소에 활용할 범위는 미리 확인하겠습니다.”

### 일반 사용자 경로

관찰: 시작 화면 이해, 원문/근거표 구분, A/B 조건 찾기, 잘못된 비교의 보류 이유 이해, 실패 후 재시도, DART 실제/캐시 구분. 금융 정답의 전문가 검수를 요청한 것으로 표현하지 않는다.

### 회계 관련 경로

먼저 실제 역할과 경험 범위를 확인한다. 관찰: PDF의 3개월/누적 열과 연결/별도 구분, KRW 백만 단위와 DART 원 단위 환산, 잘못된 비교를 차단하는 이유, 추가 검토가 필요한 상황과 설명 문구. 참여자가 확인한 범위 밖의 감사·투자 판단을 요구하거나 검수 완료로 확장하지 않는다.

이 문서에는 사용 결과, 평가 점수, 의견, 오류 발견을 채워 넣지 않았다. 실제 참여 후 별도의 익명 세션 파일에 작성한다.
