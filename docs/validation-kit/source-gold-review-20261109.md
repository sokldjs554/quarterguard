# 사람의 원문·검색 정답 검수 안내

상태: **참여 요청 준비. 실제 검수 기록 없음.** 기존 b의 앱 사용 의견과 별도의 과제다. 이 양식을 AI가 대신 채우지 않는다.

## 누구에게 무엇을 부탁할까

공시·재무제표를 읽을 수 있는 사람에게 공개 PDF의 지정 셀 8개와 자연어 질의 4개를 대조해 달라고 요청한다. 같은 친구 b에게 부탁해도 된다. 이 경우 같은 참여자의 추가 검수이며 독립 외부 전문가나 회사 승인으로 표현하지 않는다. 작성자 본인이 검수하면 작성자 검수로 기록한다. 예상 과제량은 20~30분이며 실제 소요시간은 별도 기록한다.

전달 문안:

> 이번에는 앱 사용성 대신 평가에 사용한 정답 일부가 원문과 맞는지 확인 부탁해. 삼성전자 2022년 3분기와 현대자동차 2024년 3분기 공개 PDF에서 지정한 8개 셀의 금액·연도·기간·연결 범위·통화·단위·행·열을 읽어서 기록해 줘. 먼저 네가 읽은 값을 적고, 그다음 저장소의 기존 정답과 대조해 일치/불일치/확인 불가를 표시해 줘. 모호하면 추측하지 않아도 돼. 질의 4개도 조건이 충분한지, 어떤 셀을 골라야 하는지 적어 줘. 실제로 확인한 범위만 익명으로 지원서·GitHub에 공개해도 되는지는 결과를 본 뒤 따로 확인할게.

## 진행 순서

1. 직무·경력·작성자와의 관계, 실제 날짜·기기·브라우저·추가 도움, 참여 동의와 공개 범위를 기록한다. 개인 실명·회사명·비공개 자료는 필요 없다.
2. [셀·질의 빈 기록지](source-gold-review-sheet-20261109.md)만 먼저 열고 공식 PDF를 확인한다. 문서와 PDF 쪽수(1부터)·표 제목·행·열을 함께 기록한다.
3. 최초 작성본을 보존한 뒤 아래 AI 작성 정답과 대조한다. 먼저 정답을 봤다면 그렇게 적고 블라인드 검수라 하지 않는다.
4. 차이가 있으면 양쪽 값·출처와 이유를 적는다. 기존 정답을 덮어쓰지 말고 별도 정정 기록으로 검토한다. 중간에 도움을 받았다면 기록한다.
5. 8개 셀·4개 질의 중 실제 확인한 수와 일치/불일치/확인 불가 수를 분리한다. 검수자는 비어 있는 칸을 억지로 채우지 않는다.
6. 공개할 익명 요약을 당사자에게 보여주고 해당 내용의 공개 동의를 확인한 뒤 사용자님이 전달한다. 자동으로 연락하거나 사람의 답변을 생성하지 않는다.
