# 세션 a — 개발자 시연과 대학생 1명의 피드백

기록일: 2026-11-08. 실시일: 2026-11-07 KST. 근거: 진행자가 제공한 관찰 기록과 이후 역할·공개 동의 확인. 녹음·동영상이나 별도 응답 JSON은 제출되지 않았다. 이 문서는 해당 기록을 정리한 공개 요약이다.

## 역할과 공개 범위

- 진행자/조작자: 프로젝트 작성자. 아래 앱 조작, 원문 확인과 산술 대조는 모두 작성자가 수행했다.
- 참여자: 실제 대학생 1명, 익명 ID `a`. 종료 질문에 대한 의견을 제공했다. 금융 실무 경력은 수집하지 않았다. 참여자가 독립적으로 업무를 완료한 기록이나 금융기관 환경 검증으로 해석하지 않는다.
- 진행자는 대학생이 실제로 의견을 제공했으며 익명 요약의 GitHub·지원서 활용에 동의했다고 확인했다. 서명된 동의서나 녹취를 별도로 확보했다는 뜻은 아니다. 이름·학교·연락처는 공개하지 않는다.
- 원기록 관리자는 진행자이며 보관/삭제 예정일은 미지정이다. 추가 인용·자료 공개는 이번에 확인한 익명 요약 범위를 넘지 않도록 별도로 확인한다.

## 대학생이 제공한 의견 — 진행자의 요약

아래는 녹취의 직접 인용이 아닌 실제 답변을 진행자가 정리한 내용이다.

|질문|답변 요약|
|---|---|
|가장 번거로운 부분|작은 근거 패널에서 PDF의 행·열을 읽기 어려워 별도 탭과 페이지·열 제목 확인이 필요했다. 기간·범위를 나란히 보여주는 보류 사유는 이해하기 쉬웠다.|
|보고서에 사용하기 전 확인할 점|회사·항목·연도·연결/별도·단독/누적·통화·배율·원문 행·열, 정정·갱신 여부를 확인하고 근거 페이지와 계산식을 남기겠다.|
|개선 의견|선택한 근거를 크게 보기, 반기 보고서 안의 2분기 단독처럼 문서명과 실제 비교 기간을 더 분명하게 표시, 보류 안내에서 B의 기간·범위 설정으로 바로 이동.|

진행자의 환경 관찰: 첫 접속~작업 화면 관찰 사이 약 100초에는 기록과 진행 간격이 포함되므로 서버 응답시간으로 단정하지 않는다. 기존 PDF 탭에서 페이지 주소만 p.48→p.104로 바꾸자 이전 쪽이 남았고, 뷰어 쪽 번호에 104를 입력해 확인했다. 이번 환경의 관찰이다.

## 이 기록으로 말할 수 있는 범위

작성자 시연·원문 대조와 대학생 1명의 실제 피드백을 확보했다. 금융 실무자 검수, 참여자 독립 업무 성공률, 사용성 향상, 고객사 배포를 입증하지 않는다. 개선 후 같은 참여자에게 다시 검토받은 결과는 아직 없다. [금융 분야 지인 검토 준비](finance-peer-review.md)는 별도이며 미실시다.
