## AI의 별도 코드 대조: h25-op-period

다음은 b의 추가 발언이 아니라 검수 수신 후 AI가 대조한 내용이다. v7 동결 요청의 해시와 일치하는 입력을 확인했다.

- 원래 `core.compare()`의 반환값은 `PERIOD_MISMATCH`이며 세부 실행 조건 이력은 없다. 두 입력은 9개월과 3개월이다. 첫 `valid`가 거짓이므로 이후 `valid and ...`의 YoY 날짜 조건은 Python 단락 평가로 실행되지 않는다.
- 별도 표시 계층 `explanation_context.period_conditions()`는 모든 조건을 재계산한다. 모델에 보낸 보충 안내에는 `equal_months`와 `yoy_start_month_day` 두 실패가 모두 있다. 즉 시작 월·일 차이는 입력에도 있고 보충 안내에도 있지만, 원래 도구에서 실제 실행한 세부 분기 이력과 같지는 않다.
- 모델은 “도구는 두 기간의 시작 월·일이 다르다고 판단해 비교를 보류했습니다”라고 썼다. 입력의 차이·보충 진단과 실제 도구 실행 근거를 구분해야 한다. b의 **모호** 판정은 그대로 보존한다.
- 코드 기준: [compare](https://github.com/sokldjs554/quarterguard/blob/9f59b18c28b7956460fc45e55e30aab9079b6c03/quarterguard/core.py#L83), [별도 설명 진단](https://github.com/sokldjs554/quarterguard/blob/9f59b18c28b7956460fc45e55e30aab9079b6c03/quarterguard/explanation_context.py#L33).
