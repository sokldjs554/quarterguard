## 명시적인 확인 필요 사례

`data/cases.json`의 누적·분기, 연결·별도, 통화, 음수 기저, 수집 범위 밖 기간은 실제 수치에서 일부러 잘못된 비교 조합을 만든 회귀 사례다. 원문 공시 자체가 잘못됐다는 뜻은 아니다. NUMERIC_CONFLICT·ZERO_BASE·출처 누락·회사/항목 불일치는 단위 테스트의 합성 반례로 검증하며 실제 공시 오류 발견 사례라고 주장하지 않는다.

## 남은 한계

- 회사 1개, 문서 2개, 정해진 표 4개. 전문가·사람 정답 검수 없음.
- 36개 질의는 템플릿으로 생성된 개발 회귀셋이며 훈련/튜닝과 독립된 보류 평가셋이 아니다.
- 생성형 모델, LLM-as-judge, 자유로운 LLM 계획/재시도, 토큰 비용 최적화는 수행하지 않았다.
- 실제 도구 실패는 trace에 남기지만 영구 저장·사용자별 기록·관측 대시보드는 없다. 공개 데모 결과는 다운로드 가능한 JSON이고 서버 재시작 후 별도 보존되지 않는다.
- 신경망 리랭커, 대규모 벡터 DB, 다중 기업, 정정공시 버전 추적, 정밀 PDF bbox 강조는 미구현.
- 무료 Render는 유휴 후 절전되어 초기 접속이 느릴 수 있다. 실제 고객 트래픽·금융 운영·보안 인증 경험은 없다.

## 독립 AI 리뷰의 추가 발견과 수정

1. **참고 달러 환산 기준:** Q3 주석 2.3은 KRW 1,352.4/USD, 반기는 1,349.5/USD를 사용한다. 수정 전 같은 USD라는 이유로 Q3/Q2 매출 비교가 6.5617%로 통과했으나 원화 기준은 6.7916%다. 환산 성격·환율·주석 페이지를 보존하고 참고 USD의 산술 비교/차감을 차단했다. 정상 외화 표시 재무제표까지 일반화하지 않는 보수적 정책이다.
2. **검색 조건 무시:** 다른 기업·지원하지 않는 분기/통화·충돌하는 기간 조건을 무시하고 삼성전자 사실을 반환했다. 지원 기업을 명시하도록 하고 충돌/미지원 조건에서 빈 결과를 반환한다. `2024년`도 연도로 해석한다. 임의 자연어 이해를 보장하지 않는다.
3. **헤더 순서/날짜:** 단어 포함 검사만으로는 누적/분기 순서 변경을 발견하지 못했다. 전체 기간 그룹 순서와 실제 종료일·연도·열 헤더를 검증한다. 환산 주석도 수집 시 검증한다.
4. **출처 검증:** 형식만 확인하던 검사를 manifest의 실제 문서 URL·해시·허용 표 페이지·행·열 대조로 강화했다. 업무 gold에 기대 evidence 전체를 고정해 exact match도 측정한다. 공개 API는 사용자 수치/출처 입력을 받아들이지 않는다.
5. **전체 MCP 실패:** 호출 수가 0일 때 평가기가 0으로 나누었다. 실행 성공률·사례 정답률·거부 원인 정확도를 분리하고, 호출이 없으면 도구 성공률을 null로 기록한다.

`tests/test_review_regressions.py`에서 수정 전 6개 테스트가 15개 하위 실패와 1개 오류를 재현했고, 수정 후 전체 테스트 38개가 통과했다. 리뷰는 별도 AI 에이전트가 수행했으며 사람 검수나 외부 협업으로 표현하지 않는다.
