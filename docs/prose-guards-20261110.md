# v5 검수 후 설명 오류 방어 — 2026-11-10

**구현·오프라인 회귀 완료. 새 모델 생성 효과와 사람 재검수는 미수행.** 기존 b의 [참6·모호1·거짓1 판정](validation-kit/session-b-v5-20261110.md), 원응답, 비용, 동결 입력, 자동 평가 기록은 그대로 보존한다. 아래 결과는 AI가 수행한 개발 회귀이며 사용자나 b의 직접 테스트로 기록하지 않는다.

## 원인과 변경

기존 지침은 근거 부재와 비교 보류를 충분히 구분하지 않았고 `If context needs review, explicitly say so`라는 일반 지침이 있었다. 실제 period-mismatch에는 근거2개가 있는데 검색 부재 문구가 붙었고, no-evidence에는 `context needs review`가 그대로 출력됐다. 프롬프트가 유일한 원인이라고 입증한 것은 아니지만 이 두 상태를 명시적으로 분리할 필요가 있다.

서버의 `generate_public()`은 상태·값·문제 목록·근거ID만 대조해, 본문이 다른 보고서를 ‘같은 보고서’로 지칭하거나 증가율에서 `%`를 빠뜨려도 통과시켰다. 구조화 인용 일치는 본문 인용 정확성을 보장하지 않는다.

|문제|생성 지침 보완|표시 전 방어|
|---|---|---|
|근거가 있는데 검색 부재로 표현|근거 유무와 비교 가능 여부를 구분. 근거가 있으면 실패한 비교 조건만 설명|근거가 있는데 지정된 검색 부재 표현이 나오면 보류|
|서로 다른 보고서를 같은 보고서로 지칭|문서ID가 여러 개면 각 문서명·페이지를 명시|여러 문서ID에서 ‘같은/동일 보고서·문서’, `same report/document` 표현을 보류|
|증가율 `%` 누락|반올림·반복을 포함해 매번 `%` 표시|증가율 이름 뒤의 숫자와 정확한 도구 성장률 값에 단위가 붙는지 검사. `%`, `％`, `퍼센트`, `percent` 허용|
|영어 내부 상태 노출|확인할 사항을 한국어로 설명|`context needs review`, `needs_review` 표현을 보류|

잘못된 문장을 자동 교정하지 않는다. 거부 응답은 `EXPLANATION_VALIDATION_REJECTED`와 검사별 Boolean만 반환하고 생성 문장·근거 안내를 반환하지 않으며 성공 캐시에 저장하지 않는다. 규칙 파일의 해시도 캐시 버전에 포함해 이전 검사로 통과한 응답을 재사용하지 않는다. 화면에는 ‘설명 표현 검사 불일치’를 포함한 보류 안내를 표시한다.

프롬프트 수정만으로 끝내면 같은 오류가 다시 화면에 노출될 수 있고, 자동 문장 교정은 실제 생성물과 보정 결과를 혼동시킨다. 따라서 **지침 명확화 + 제한된 표현 검사 + 원문 보존**을 적용했다. 자유 문장 전체를 규칙으로 인증하거나 정상 설명을 템플릿으로 교체한 작업은 아니다.

## 남은 한계

- 표현 검사는 한정된 패턴이다. 다른 한국어 표현·대명사·긴 문장·한글로 쓴 숫자, 레이블 없이 반올림한 비율의 단위 누락은 놓칠 수 있다. 문서가 여러 개 있는 설명에서 일부 사실만 같은 문서를 가리키거나, 검색 부재를 부정·인용한 문장도 보수적으로 보류할 수 있다. 이때는 명시적인 문서명과 조건 설명이 필요하다.
- 이 규칙은 모든 숫자·기간·출처의 의미 정확성을 보장하지 않는다. 기존 수치/인용 감사와 사람 검수의 필요성을 대체하지 않는다. `prose_semantics_verified=False`를 유지한다.
- 새 프롬프트로 실제 생성한 응답은 아직0개다. 같은8건에서 새 오류가 줄었는지, 처음 보는 사례에 적용되는지, b가 수정 후 어떻게 판정하는지는 미검증이다. 기존 v5 동결 파일·예산은 그대로 두며 변경된 코드에서 과거 동결의 실행은 해시 검사로 거부된다. 다음 실호출은 새 입력·코드·비용 범위로 별도 승인해야 한다.
- 추가 유료 호출0회, 추가 비용0. 실제 청구액 조회도 하지 않았다. 새 사용자 참여·회사 환경 배포 없음.

지원서에는 “사람 검수에서 드러난 설명 오류를 회귀 사례로 보존하고, 근거 부재·문서 지칭·비율 단위·내부 표현에 대한 출력 보류 규칙을 추가했다”라고 쓸 수 있다. “LLM 정확도 향상 확인”, “새 응답 전문가 검수 완료”, “환각 제거”로 표현할 수 없다.
