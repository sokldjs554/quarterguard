## 평가·사람 검수

- 구조: JSON 값·status·issues·근거ID 순서를 도구와 정확히 대조한다. `%`를 지워 통과시키지 않는다.
- 설명: 수치·기간·범위·단위·문서·페이지와 보류 이유를 대조한다. QoQ에서 둘 다3개월이지만 인접하지 않은 날짜 관계를 구체적으로 설명하는지 확인한다.
- 전후: v6 당시 자동 점수, v6를 현재 규칙으로 재검사한 점수, v7 새 응답을 구분한다. 질문·도구 결과가 같은16건을 모두 쌍으로 비교하고 악화도 공개한다.
- b: [재검수 안내](validation-kit/llm-prose-v7-review-20261110.md)에 따라 새 응답을 먼저 읽고 이전 응답과 비교한다. 생성 후 실제 문장·구조 필드·도구 결과·발행사 PDF 링크와 문서·페이지·행·열을 제공한다. 사람 판정은 빈칸에서 시작한다.

새 PDF·MCP 실행이 아니라 과거 원문 파싱·도구 결과 재생이다. 이미 수정에 사용한 사례이며 독립 holdout·일반 정확도 평가가 아니다. 평가 모델 GPT-5.4 mini와 공개 제품 GPT-4.1 mini도 구분한다. LLM-as-judge는 사용하지 않는다.

## 실행 통제·검사

별도 `evaluate_live_explanations_v7`와 `live-explanations-v7.yml`을 준비했다. 승인·동결 해시·코드·입력이 맞지 않으면 키 사용·HTTP 이전에 중단한다. Workflow는 재실행과 이전 dispatch 존재를 검사한다. 출력은 별도 새 디렉터리이며 과거 결과를 덮어쓰지 않는다. 승인 후 dispatch는 한 번만 실행한다.
