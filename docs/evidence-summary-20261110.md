# 최신 근거와 과거 평가 표시 정리 — 2026-11-10

공개 데모의 ‘현재 보완 결과’가 2026-10-31 집계를 표시해 후속 현대차 파서·사람 검수·직접 코드 실행이 없는 것처럼 읽히는 문제를 정리했다. **기존 평가·실패·빈 양식은 보존**하고 새로운 날짜별 요약을 추가했다. 금융 문서 비교·근거 확인 제품 흐름은 유지한다.

## 화면과 API

- 최신 요약을 검증 기록 위쪽에 표시한다. 현대차 원문 평가와 공개 작업지 미등록, 지정 셀·질의의 부분 사람 검수, 같은 b의 LLM 전후 판정, 근거ID 오류, 본인 직접 테스트, 참여자 역할과 고객 배포0건을 함께 보여 준다.
- 마지막 설명 방어 변경 이후 새 실호출·b 검수가 없다는 한계를 명시한다. 공개 OpenAI 활성화 상태를 정적인 평가 요약으로 판단하지 않도록 기존 제공자 상태 표시로 안내한다.
- `GET /api/evaluation/latest`는 [날짜별 요약](../data/latest-progress-20261110.json)과 현재 서버 커밋을 반환한다. 요약에 연결한 원기록의 SHA256이 다르거나 파일이 없으면503으로 보류한다.
- 기존 `GET /api/evaluation/current/progress` 응답은 변경하지 않았다. 화면에서는 ‘2026-10-31 과거 평가’ 안에 넣고 당시 미지원·미검수 표현임을 표시한다. 기존 다른 평가 API와 과거 설명 응답도 그대로다.
- 화면의 10월29일 추가 평가와 초기 CI 기록에도 과거 기록임을 명시했다. 모바일 최신 요약은 항목별 결과와 한계를 세로로 읽을 수 있게 했다.
- 최신·과거 자료는 독립적으로 불러온다. 최신 실패 때 과거 기록을 최신으로 대신 표시하지 않고 재시도 버튼을 제공한다. 과거 자료만 실패하면 최신 요약은 유지한다.

## 숫자와 주체

요약의 Python191개는 **직전 기능 변경 `f5377ad`에서 AI가 실행한 기록**이다. 이번 화면 정리의 테스트 수와 구분한다. 본인의 전체143개, 기간2개, DART3개는 기존 사용자 제공 기록이며 AI 통합 검사와 합치지 않는다. 147개는 DART 통합 당시, 167개는 PR #24 당시 기록으로 지원 문서에 시점을 명시했다.

LLM은 초기4회와 이후 두 배치 각8회를 구분한다. 같은 개발8개에서 b의 설명 판정은 참5·모호3→참7·모호1, 구조 필드는8/8→7/8이다. 원문·기존 판정을 새로 작성하지 않았다. 마지막 방어 변경의 실호출 효과는 아직 미검증이다.

a는 작성자 시연에 의견을 준 대학생, b는 직접 과제와 후속 검수를 한 금융 분야 경력3년인 친구다. 두 명의 역할을 구분하며 b의 여러 후속을 새 참여자로 세지 않는다. 현대2025의 모든 정답이 사람 검수됐다고 표시하지 않는다.
