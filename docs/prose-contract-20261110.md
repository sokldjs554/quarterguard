# v6 검수 후 JSON 값·부정문·기간 안내 보완

기준은 `952ef5f`의 실제 v6 응답16건과 b의2026-11-10 18:47 KST 검수다. 이번에는 코드와 오프라인 회귀를 보완했다. **새 LLM 호출0회·새 사람 검수0건**이며 새 모델 응답의 정확성 개선으로 해석하지 않는다.

## 변경과 실제 확인 범위

1. `quarterguard/explanation_context.py`의 지침은 JSON `value`를 도구 문자열 그대로 복사하고, `%`는 `explanation_ko` 본문에만 붙이도록 구분한다. `public_providers.build_payload()`는 요청별 JSON Schema `value.enum`을 도구 값 하나(보류 시null)로 제한한다. 단순 지침 변경에만 의존하지 않으며 서버의 기존 정확한 문자열 대조도 유지한다. 잘못된 응답의 `%`를 제거하거나 과거 점수를 고치지 않는다. 로컬 JSON Schema 검사로 값·null·파생값과 잘못된 표기를 대조했다. **변경된 스키마의 실제 제공자 수락과 생성 효과는 아직 실호출하지 않았다.**
2. `explanation_guards.check_prose()`는 완결된 “근거가 없는 것은 아닙니다.”와 “근거가 없다는 뜻은 아닙니다.”처럼 명시적으로 부재를 부정하는 두 문형만 예외 처리한다. “근거가 없습니다”, 의문형·불확실한 이중 부정, 뒤에 이어지는 실제 부재 주장은 계속 차단한다. 문장 전체를 건너뛰지 않고 각 출현을 검사한다. 한국어 의미 분석기나 모든 부정문 지원이 아니며 미지원 표현은 과도하게 보류될 수 있다.
3. `explanation_context.period_decision()`은 정본과 정확히 일치하는 두 근거, 비교 방식이 있을 때만 개월 수·QoQ 인접성·YoY 연도/종료월/시작 월일 조건을 대조한다. `PERIOD_MISMATCH`가 보고된 경우 실패한 조건만 `failed_conditions`와 안내로 제공한다. 알려지지 않은 값·변조된 날짜·개월 수·지원하지 않는 문맥은 확인 필요로 남긴다. 누적 차감의 세부 원인은 이번 진단 지원 범위 밖이다. 도구의 상태·문제 목록·계산 결과는 변경하지 않는다.

예: 삼성2022 Q3와2021 Q3는 모두3개월이지만 QoQ로는 `qoq_adjacent`가 실패한다. 안내는 **“A 시작일이 B 종료일 다음 날이 아니므로 인접한 분기 관계가 아닙니다.”**다. b가 모호로 판정한 기존 모델 문장은 수정하지 않으며 그 옆의 도구 안내만 명확해졌다. 새 프롬프트가 실제로 명확한 문장을 생성할지는 후속 실호출·검수가 필요하다.
