# 작업 중심 UI 재구성 · 2026-11-14

이전 C안의 색상 변경에서 화면 구조 자체를 바꿨습니다. 사용자가 제시한 AutoFix의 명확한 시작 흐름과 BiddingFlow의 작업별 화면 분리를 참고했습니다. 코드·이미지를 복제하지 않았으며, 고객·활동·운영 통계를 만들어 표시하지 않습니다.

## 바뀐 흐름

- 첫 화면에서 삼성전자 분기 비교 / SK하이닉스 연간·잔액·제품 비중 / Apple 선택 질문 검토를 고릅니다.
- 탐색 메뉴: 검토 시작 → 분기 비교 / 문서 분석 / 근거 검색 / 검증 기록.
- 분기 비교: 선택 항목 A/B 금액·실제 기간·범위·단위·판정 요약을 먼저 보여줍니다. 6개 항목 표는 전체 너비를 사용합니다.
- 수치 비교 / 원문 근거 / 개인 메모를 별도 탭으로 분리했습니다. 금액을 누르면 해당 수치의 원문 근거 탭이 열리고 비교표로 복귀할 수 있습니다.
- SK·Apple 도구는 근거 검색 하단에서 독립된 문서 분석 화면으로 이동했습니다. 기존 검색·계산·JSON 저장·다시 읽기 모듈을 그대로 사용합니다.
- 모바일 탐색, 키보드 탭 이동, 건너뛰기, URL 해시·뒤로/앞으로 이동을 지원합니다.

## 보존한 범위

금융 파서·검색·계산·LLM 검증 코드는 변경하지 않았습니다. 원문 PDF와 수집 수치 재구성 표를 구분합니다. 이전 평가·실패·참여 기록은 수정하지 않았습니다. 이번 검사 수행자는 AI이며 실제 참여자 b의 추가 사용 기록이 아닙니다. 유료 API 호출 0회입니다.

새 화면 흐름의 pending/503 응답은 오류 상태 확인용 주입입니다. 정상 계산은 실제 서버로 실행했습니다. 브라우저는 Chromium 에뮬레이션이며 실제 휴대폰 사용 검사로 세지 않습니다. 로컬 HTTP 검사와 배포 후 HTTPS 검사는 별도 기록입니다.

초기 홈 부재 실패와, 메모 탭에서 돌아올 때 비교표를 열지 않던 수정 전 실패도 [산출물](../artifacts/task-workspace-20261114/)에 보존했습니다. 별도 코드 검토가 메뉴 복귀·건너뛰기 수정 후 동작을 재확인했습니다.

## 재현

```bash
python -m uvicorn quarterguard.api:app --host 127.0.0.1 --port 8015
# 다른 터미널; 산출물 폴더는 새 경로 지정
DEMO_URL=http://127.0.0.1:8015 WORKSPACE_QA_DIR=work/my-workspace-check python scripts/browser_workspace_check.py
python -m unittest discover -s tests
node --test tests/*.mjs
```

1. `/` 또는 `/#home`에서 기업별 작업을 선택합니다.
2. `/#work`에서 매출 금액 → 원문 근거 → 비교표 복귀를 확인합니다. B를 누적·별도로 바꿔 보류와 복구를 확인합니다.
3. `/#analysis`에서 SK 계산 또는 Apple 질문 검토를 수행하고 JSON을 저장·다시 읽습니다.
4. `/#review`에서 실제 실행·저장 기록·과거 평가의 구분을 확인합니다.
