# 승인된 워크북 디자인의 제품 적용
사용자는 비교 PDF와 조작 시안을 확인한 뒤 “그래 괜찮네 진행해도 돼”라고 승인했다.
기준: /workspace/outputs/quarterguard-workbench-review-20261115/index.html 및 requirements.md.

방향: 상단 작은 탐색, 삼성 기업 헤더, A/B 조건이 붙은 6행 비교표, 아래 선택 항목의 계산과 양쪽 근거. 모바일에서 A/B와 판정 동시 표시, 보류 복구를 표 위에 제공.
기존 기능은 유지한다: 전체 비교 조건, 실제 MCP 재검증, 근거표/PDF, 개인 메모/확인 표시, CSV, SK/Apple 검색·계산·JSON 재확인, 검색, 평가 기록, 외부 제공자 명시 호출.
기존 대형 KPI·그래프를 표 위에 다시 쌓지 않는다. 왼쪽 고정 메뉴와 일반 채팅 UI를 넣지 않는다.
접근: 기존 vanilla JS와 서버 API를 유지하며 DOM 배치·공용 스타일·선택행 시각화만 변경. 시안 저장 응답은 제품에 포함하지 않는다.
대안: 시안 자체를 그대로 덮어쓰면 전체 조건·MCP·메모 기능이 유실된다. 기존 CSS에 색만 덧씌우면 승인한 구조가 구현되지 않는다. 기존 기능 모듈을 유지한 DOM 재배치를 선택했다.
이번 승인은 제품 적용을 진행하라는 승인이다. 과거 공개·배포 승인도 유지된다. 기존 실패/사람 검수 기록을 수정하거나 새 사람 결과로 표시하지 않는다. 유료 모델 호출 없음.
