# 공시 대조 작업지

사용자가 UI 조사 결과의 수정 착수를 지시했다. 사례 갤러리 대신 문서·수치·불일치를 직접 검토하는 작업지로 교체한다. 색상 변경으로 기존 대시보드를 유지하는 방식은 제외한다.

## 근거와 접근

DataSnipper의 검토표와 문서 병치, BamSEC의 위치별 차이, Hebbia/AlphaSense의 문서 비교표를 참고한다. ARIA의 문서 처리 목록은 미처리 항목 흐름의 참고이며 외형을 복제하지 않는다. 조사 원문 링크는 docs/ui-research.md에 남긴다.

선택한 접근은 가로 작업 도구 모음 + 6개 재무 항목 비교표 + 상시 근거 패널이다. 대형 결과 카드와 고정 사례 메뉴를 제거한다. 문서 큐 중심 화면은 현재 두 문서 데이터 규모보다 과하고, 메모 편집 중심 화면은 수치 대조를 가리므로 주 화면으로 사용하지 않는다.

## 동작과 제약

- 양쪽 문서/연도/단독분기·누적/연결·별도/통화를 개별 선택한다. QoQ/YoY를 선택하고 기존 Decimal 가드로 6개 항목을 계산한다.
- 초기/설정 변경은 서버의 표 계산이며 과거 MCP 재생이나 현재 MCP 실행으로 표시하지 않는다. 재검증 버튼은 실제 stdio MCP 세션에서 6개 항목의 근거 조회·비교를 실행한다.
- 행/숫자 선택은 해당 문서·행·열의 재구성 근거표로 이어진다. 원문 PDF는 발행사 주소를 iframe/새 탭으로 직접 연다. 원본을 서버에서 프록시하거나 재배포하지 않는다. 재구성 표는 원문 스크린샷으로 표시하지 않는다. PDF 뷰어 지원 여부/외부 연결 실패를 성공으로 주장하지 않는다.
- 현재 검증 데이터는 삼성전자 IR 두 건이다. 기업은 예시 데이터로 표시하고 지원하지 않는 기업 선택지를 만들지 않는다. 실제 다중 기업 지원은 별도 수집/평가 후에만 주장한다.
- 오류는 관련 행과 기간/범위 문맥 가까이에 표시한다. 계산 불가 시 성장률을 숨긴다. 설정 변경 시 과거 실행 trace와 성공 상태를 폐기한다.
- 검색·평가는 보조 화면이다. 평가에는 구성별 수치뿐 아니라 사례별 정답/출처/실행 성공을 노출한다. 이전 사례의 누적 차감·음수·근거 없음 검증과 준비 재생도 평가 화면에서 접근 가능하다.
- 명사형 제목, 키보드 포커스, 의미 있는 버튼명, 390px 모바일 본문 넘침 방지. 모바일에서는 표와 근거 패널을 세로로 배치한다.
- 기존 API/평가 산출물과 실제 LLM/DART CI 기록을 보존한다. 공개 데모에 유료 모델 호출을 추가하지 않는다.

완료 기준: 관련 금융/API 회귀 및 실제 MCP 테스트, 새 PC/모바일 브라우저 흐름, 비동기 실패/복구 검증, 새 화면 스크린샷과 README, PR/CI와 배포 commit 확인.
