# QuarterGuard C안: 짙은 탐색 영역과 밝은 검토 화면

사용자가 공식 UI 조사 후 C안을 선택했다. 기존 금융 문서 검토 흐름에
짙은 청록색 탐색 영역, 밝은 비교표와 원문 패널을 적용한다.

## Approaches
- A: 밝은 회청색 작업지 — 익숙하지만 기존 화면과 차이가 작다.
- B: 따뜻한 미색 작업지 — 문서에 어울리지만 기존 Ramp 방향과 가깝다.
- C (사용자 선택): 짙은 탐색 영역 + 밝은 작업지 — 영역을 구분하면서
  흰 PDF와 재무표의 가독성을 유지한다.

## 적용
- 탐색 배경 #17252B, 작업 배경 #F2F5F6, 표/원문 #FFFFFF.
- 짙은 청록색 버튼과 선택 강조. 보류는 황색, 정상은 녹색과 문구 병기.
- 기존 HTML/CSS에 적용하며 새 라이브러리, 외부 폰트, 유료 API는 추가하지 않는다.
- 비교표와 근거 패널의 경계, 숫자 정렬, 작은 보조 글자, 키보드 초점을 정돈한다.
- 모바일은 문서 목록을 가로로 유지하며 금액 아래 기간/범위/단위를 보존한다.
- 비교 조건, 보류, 복구, 저장, 원문 링크, API 동작과 평가 결과는 변경하지 않는다.

## 검증과 기록
320/390px 모바일 및 PC에서 정상 비교, 기간/범위 보류와 복구,
근거 선택, 검색/계산/내보내기, 오류 후 이전 결과 제거를 확인한다.
기존 브라우저 스크립트와 Node 테스트를 재사용한다. 새 캡처와 로그는
artifacts/ui-c-20261114에 별도로 저장하고 과거 근거는 덮어쓰지 않는다.
공개 반영 전 diff와 화면을 확인하고, 반영 후 서버 커밋/스타일을 대조한다.
색상·간격의 세부 값은 이 선택을 구현하기 위한 개발 판단이다.
