# v7 결과 게시 검사

Python238·Node14·로컬 브라우저10검사는 AI가 실행한 게시/회귀 검사다. 실제 모델16회와 합산하지 않는다. 브라우저는 로컬 실제 요약 API와 실패 주입을 사용했으며 물리 모바일·직접 공개 HTTPS·새 사람 검수가 아니다. 이 게시 검사의 추가 유료 호출0회.

before.txt는 새 v7 요약 필드 추가 전 실패, python-tests.txt/node-tests.txt/browser.json은 반영 후 검사다. 과거 데이터와 원응답20파일의 바이트 보존도 확인했다. 배포·공개 서버 일치는 게시 PR에서 확인한다.
