# QuarterGuard

공식 금융 문서의 **원문 근거·기간·연결 범위·통화·단위**를 확인해 계산하거나 보류하는 금융 검토 작업지입니다. AI 코딩 도구를 활용한 개인 프로젝트이며, 계산 판정은 규칙과 Decimal 연산으로 수행합니다.

**최신 사람 확인·지원서 준비:** [실사용11과제·실제 LLM20건·빈 기록지](docs/validation-kit/final-handoff-20261112/README.md) · [확인된 근거로 쓴 지원서 초안](docs/application-evidence-20261112.md). [후속 제출 기록](docs/validation-kit/final-followup-20261112/README.md)을 받았습니다. 기존 참여자 b가 데모11과제와 실제 응답20건을 직접 확인했다고 후속 확인됐습니다. A7·S4의 저장 확인은 부분 완료입니다. 제품 응답4건은 설명 참2·거짓2로 판정됐고, v9 16건은 참13·모호3입니다. 최초 제출의 AI 검토 표기는 사용자 확인에 따라 정정했고 원기록은 보존했습니다. 새 유료 호출0회.

**남은 저장 동작 기술 점검:** [A7·S4 다운로드·질문 변경 후 상태](docs/final-export-verification-20261112.md)를 PC·모바일 크기의 자동 브라우저로 확인했습니다. S4가 연간 증감률처럼 보이는 문구도 수정하고 공개 배포 후 두 화면 크기에서 재확인했습니다. b의 실기기 저장 재확인과는 구분합니다.

## 현재 검증과 미완료 사항

**Apple 제품 지원 추가:** [원문·계산·보류와 수정 후 평가](docs/apple-product-support-20261112.md). 동일 개발7문항7/7, AI 합성 변형19/19. 원문 HTML25셀·2문단 추출, 지정19셀 대조. Python339개 실행·실패0·1skip, Node18개 통과. 새 LLM 호출0회. 첫 실패·중간 실패를 보존했으며 새 독립 평가/사람 재검수로 세지 않습니다.

**새 Apple7문항 첫 평가:** [수정 전 결과와 SEC 원문 대조](docs/apple-first-evaluation-20261112.md). 수정 전 제품 근거 검색0/7, 당시 선택 문서 미등록을 확인했습니다. 별도 평가용 HTML 대조에서는19개 수치가 제출값과 일치했습니다. 제품 파서 지원·PDF처리·사람 추가 검수로 세지 않으며, 작성자는 본인이 AI 없이 직접 작성했다고 후속 확인했으며, 동결 원본과 확인 기록을 따로 보존합니다.

**제품 동일 모델 실호출 완료:** [실제18회·추정$0.0081864](docs/final-live-results-20261111.md). 설명은 당시3/4자동통과했지만 금액 표기 오류2건을 새로 발견해 후속 검사에서 차단했습니다. 같은 원응답 재생은1/4통과이며 새 생성이 아닙니다. 실제 모델 도구 선택은3/4과제 기준 일치,1과제는 근거 조회 생략으로 차단됐습니다. [후속 제출 판정](docs/validation-kit/final-followup-20261112/README.md)은 설명 참2·거짓2, 구조 일치3·불일치1이며 기존 참여자 b가 직접 판정했다고 확인됐습니다. 기존 빈 양식은 보존했습니다.

- **원문:** 삼성2문서4표192셀과 SK하이닉스3쪽18셀을 원문 PDF부터 다시 대조했습니다. [이번 원문·MCP 기록](artifacts/final-hardening-20261111/).
- **회귀:** Apple 추가 후 Python339개 실행, 실패0·1개 건너뜀. Node18개 통과. 이전 보완 당시 Python321개·Node14개 결과는 보존했습니다. 최종 결과는 [완료 기록](docs/final-readiness-20261111.md)에서 확인합니다.
- **LLM:** v9는 기존 개발16건에 대한 GPT-5.4 mini 새 생성입니다. 제품 검사16/16, **b의 v9 문장 검수는 참13·모호3**입니다. [수행 출처 정정 기록](docs/validation-kit/final-followup-20261112/v9-human-review-correction.json)을 따릅니다. 제품과 동일 모델·프롬프트·응답 검사로 실제18회 실행한 결과는 위 별도 기록에서 확인합니다.
- **사람:** 외부 고유 참여자2명(a대학생, b금융 분야3년 경력의 친구). 실제 사용·후속 검수 기록이 있습니다. 최신 SK 화면 사용은 기존 참여자 b가 직접 수행했다고 확인됐으며, 직접 PDF 대조와 S4 파일 내용 확인은 이번 제출로 입증되지 않았습니다. 새 Apple7문항은 본인이 AI 없이 직접 작성했다고 확인한 자료이며, 수정 전 최초 실행과 별도의 AI 원문 대조를 기록했습니다. 기존 본인 작성 SK5문항은 수정에 사용한 개발 사례입니다.
- **운영:** 공개 서버의 작은 순차 표본을 측정했습니다. 최초30초 접속 시간초과도 보존했습니다. 고객 트래픽·가용성 보장·금융기관 배포 경험으로 표현하지 않습니다.
- **본인 수행:** 기간2개·DART3개·추가 진단1개 테스트와 기간 진단 구분 코드 기록을 AI 작업과 구분했습니다.

## 5분 재현

1. 작업지에서 삼성 A/B 매출의 원문·페이지·행·열을 확인하고 +6.7916%를 확인합니다.
2. B를 누적 또는 별도로 변경해 계산 보류를 확인하고 수정 버튼으로 복구합니다.
3. 비교 검증의 실행 기록에서 실제 MCP와 준비된 기록 재생을 구분합니다.
4. 근거 검색 → SK하이닉스 → 선택 근거로 계산에서 현금 증감, DRAM 비중, 음수 기준값 보류를 확인합니다.
5. Apple 문서를 선택해 질문의 근거·계산을 검증하고 집계/인과관계의 판단 보류를 확인합니다.
6. JSON을 저장해 원문 위치·A/B 조건·판정·공식을 재확인합니다. 개인 확인 표시는 계산 승인이 아닙니다.

## 로컬 실행

Python3.12 권장. 기본 앱·회귀 테스트는 유료 API 호출 없이 실행합니다.

```bash
git clone https://github.com/sokldjs554/quarterguard.git
cd quarterguard
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python -m uvicorn quarterguard.api:app --host 127.0.0.1 --port 8000
```

```bash
python -m unittest discover -s tests
node --test tests/*.mjs
python scripts/check_artifacts.py
python -m quarterguard.final_evaluation --dry-run --output work/new-free-mcp-run
```

`--dry-run`은 실제 MCP를 호출하지만 도구 선택은 준비된 테스트 순서이며 LLM 호출0회입니다. 출력 폴더는 새 경로를 사용합니다. PDF 캐시가 필요한 테스트는 캐시가 없으면 건너뜁니다.
