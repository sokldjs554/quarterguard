## 5분 사용 순서

1. **재무 비교**에서 삼성전자 2024년 3분기 매출 **79,098,731백만 원**, 2분기 **74,068,302백만 원**, **+6.7916%**를 확인합니다. 숫자를 누르면 원문 근거 창이 열리며, **근거표·원문 보기**로 PDF 위치와 행·열을 확인합니다.
2. B의 기간을 **누적**, 범위를 **별도**로 바꿔 계산 보류를 확인합니다. 표 위 **B 기간 수정 / B 범위 수정**으로 조건을 고친 뒤 **설정 닫고 결과 보기**로 돌아옵니다. **전체 비교 조건**에서는 A/B 문서·연도·범위·기간·단위와 QoQ/YoY를 선택합니다.
3. **비교 검증 → 실행 상세**에서 실제 MCP 도구 실행을 확인합니다. 일반 조건 변경 시의 표 계산과 구분합니다. **개인 메모** 탭의 확인 표시는 계산 승인과 별개이며, 메모와 기존 **25열 CSV**를 유지합니다.
4. **문서 분석**에서 SK하이닉스를 선택하고 **선택 근거로 계산**을 펼칩니다. 현금 증감 **47.6820%**, DRAM 비중 **67.5777%**, 음수 기준값의 증감률 보류와 재고 개월분의 정의 확인을 살펴봅니다.
5. 문서를 Apple로 바꾸고 **질문의 근거·계산 검증**을 실행합니다. 제품·서비스 매출총이익률 **37.1806% / 73.8804%**와, 개별 수익성·판매량 단독 원인 질문의 판단 보류를 확인합니다.
6. 분석 결과를 JSON으로 저장한 뒤 **저장한 JSON 파일 확인**에서 내려받은 파일을 선택해 현재 결과와 대조합니다. 파일은 브라우저 안에서 읽습니다. 질문이나 조건을 바꾸면 이전 결과와 저장 상태가 초기화됩니다.

## 로컬 실행

Python3.12 권장. 기본 앱·회귀 테스트는 유료 API 호출 없이 실행합니다.

```bash
git clone https://github.com/sokldjs554/quarterguard.git
cd quarterguard
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python -m uvicorn quarterguard.api:app --host 127.0.0.1 --port 8000
```

```bash
python -m unittest discover -s tests
node --test tests/*.mjs
python scripts/check_artifacts.py
python -m quarterguard.final_evaluation --dry-run --output work/new-free-mcp-run
```

`--dry-run`은 실제 MCP를 호출하지만 도구 선택은 준비된 테스트 순서이며 LLM 호출0회입니다. 출력 폴더는 새 경로를 사용합니다. PDF 캐시가 필요한 테스트는 캐시가 없으면 건너뜁니다.
