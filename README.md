## 직접 확인하기

공개 작업지는 **삼성전자2024 반기·3분기 문서2건, 정본192개**입니다. 현대차는 파싱·격리 평가를 지원하며 공개 기업 선택에는 등록하지 않았습니다.

1. A/B 수치 선택 → 발행사 원문 PDF·페이지·행·열 확인.
2. 비교 설정에서 단독/누적 또는 연결/별도 변경 → 계산 보류 → 조건 복구.
3. 비교 검증 → 실제 MCP 도구 실행과 JSON 기록 확인. 준비된 기록 재생과 구분.
4. 근거 검색에서 `삼성전자 2024년 3분기 연결 매출액 3개월 백만원` 입력. 누락된 조건은 확인 요청.
5. 검증 기록에서 최신 평가와 원본 실패 확인. DART 직접 확인은 별도 실제 요청·캐시·차단 상태 표시.

개인 확인 표시와 메모는 자동 금융 판정을 바꾸지 않습니다. 근거 확대는 추출 수치 정보이며 원문 이미지는 발행사 PDF에서 확인합니다. 금융 문서 검토 흐름을 유지하며 채팅 UI로 바꾸지 않았습니다.

## 재현

Python3.12 권장. 기본 앱은 유료 API 키·모델 다운로드 없이 실행합니다.

```sh
git clone https://github.com/sokldjs554/quarterguard.git
cd quarterguard
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

서버를 실행합니다. 테스트는 별도 터미널에서 같은 가상환경을 활성화한 뒤 실행합니다.

```sh
python -m uvicorn quarterguard.api:app --host 127.0.0.1 --port 8000
```

```sh
python -m unittest discover -s tests -v
node --test tests/*.mjs
python scripts/check_artifacts.py
```

공식 PDF 캐시가 없는 환경은 해당 테스트를 건너뜁니다. 본인 보고239개(1개 건너뜀)와 첨부 구현만 적용한 AI검사238개(1개 건너뜀)는 별도 기록입니다. 11월11일 테스트1개를 수신해 관련24개·전체239개(1개 건너뜀)를 재확인했습니다. 앞선 실행 로그는 별도로 보존합니다. API 유료 실호출은 이 명령에 포함하지 않으며 별도 구체적 승인이 필요합니다.

원문 재평가·모델 다운로드·리랭킹 재현은 각각 [원문 평가](docs/evaluation-v2.md), [현대 후속](docs/hyundai-holdout-20261109.md), [리랭킹](docs/ranking-v2.md)을 따르고 **새 출력 파일명**을 사용합니다. 비밀키·전체 원문PDF·모델 가중치는 저장소에 포함하지 않습니다.
